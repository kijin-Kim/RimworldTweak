# 생활·단일 점유 데모 실행 안내

2026-11-15. 현재 기준은 [R 토글·점유 계약](Contracts/InteractionOccupancy.md). 실제 검사 결과는 [점유 검증 기록](Verification/2026-11-15-occupancy.md)을 따른다. 2026-11-15 사용자가 “모두 정상”으로 확인했다고 보고했다. 해상도·세부 조작 기록은 별도로 받지 않았다. 아래 절차는 이후 회귀 확인용으로 유지한다.

## 실행과 조작

실행 파일: `E:\Dev\RimworldTweak\Builds\Windows\RimworldTweak.exe`. 배포할 때는 Windows 폴더 전체가 필요하다. 에디터 장면은 Assets/Game/Scenes/SimulationSandbox.unity다.

- 정착민 삼각형/목록 클릭: 선택. 우클릭: 이동 목적지 지정. 소집 중 현재 타일 우클릭: 이동 중단.
- **R 또는 Draft [R]/Undraft [R] 버튼 하나:** 소집·해제 토글. 기존X/Stop/Release 버튼은 제거했다. R을 길게 눌러도 한 번만 토글하며 다시 누르면 해제된다.
- Space/Pause: 시간 정지/재개.1/3: 배속을 정하고 재개. . 또는 Step: 정지 중1Tick 진행. Esc: 선택해제.
- Reset: 위치·욕구·식량·침대·명령·점유·소집·수면 목적을 초기화. 정지 여부와 배속은 유지한다.

소집은 Pause 중에도 현재 행동·대기명령·점유를 즉시 취소한다. 소집 중에는 자동 생활보다 플레이어 이동이 우선하며 욕구 감소는 계속된다. 해제하면 다음Tick 현재욕구로 자동생활을 다시 선택한다. 취소한 옛 명령/점유는 복원하지 않는다.

## 점유 표시와 생활 규칙

초기8×8·정착민3명·식사18/목재40·침대2개, 욕구35/25다. 식사는포만도30이하·완료20Tick에1개소비/+60, 수면은휴식20이하에서시작해90에완료한다. 생식40Tick/식재료4개는별도시험시나리오에서검사한다.

침대와음식스택은동시에한Pawn만점유한다. APPROACH C1은1번Pawn이접근전이미점유했다는뜻, USING C1/침대SLEEPING C1은실제사용중이다. FREE는소유자가없다는뜻이다.

식량 Total/Held/Open to others는총량/현재행동확보량/다른Pawn이접근가능한량이다.18/1/0이면재고18중1개를확보했지만나머지17개도같은스택이라다른Pawn이점유할수없다.음식을다먹거나취소하면스택을해제한다.

바닥수면자는침대가비면다시탐색한다. 휴식20을넘어도90미만이며수면목적이진행중이면침대를먼저확보하고이동한다. 이동중에는수면회복을하지않으며도착다음Tick부터침대회복률을사용한다. 실패하면바닥수면을유지한다.

## 직접 확인할 5단계

1. 선택 후 R을 눌러 DRAFTED/Undraft [R] 표시를 확인한다. 길게누르거나X를눌러도상태가반복전환되지않고,R을떼었다다시누르면자동생활로돌아와야한다.
2. 자동식사중Pause→R. 즉시음식점유가FREE가되고완료전식량은차감되지않아야한다. 소집상태에서우클릭/재개하면지정타일로이동한다.
3. 대략Tick200 무렵두침대가사용되고다른Pawn이바닥에서자면Pause. 침대사용자또는접근자를선택해R. 즉시그침대의소유자가사라져야한다.
4. Step을한번진행한다. 바닥수면자가빈침대를점유하여APPROACH가되고,재개하면침대로이동해수면해야한다. 침대를향해이동중이어도FREE가아니다.
5. R해제및Reset을확인한다. 초기식사18/욕구35·25/빈침대2개로복원되고오래된점유·명령이남지않아야한다. 다양한창크기의문구/클릭위치는사람확인대상이다.

답변 예: “모두 정상”, “R을 누르면 두 번 토글됨”, “침대 주인을 소집했는데 바닥 수면자가 침대를 선택하지 않음”. 문제가 있으면Tick·Pawn번호·재현순서를함께알려주면된다. 사람확인은커밋승인이아니다.
