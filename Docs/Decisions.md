## Unity 선택의 판단 근거

2D 그리드 화면과 C# 규칙 테스트 반복에 적합하다고 판단했다. Unreal도 구현·자동 테스트가 가능하고 기존 경험을 활용할 장점이 있으나, 이번 프로젝트는 새로운 시뮬레이션 중심 구조이며 이전할 기존 소스가 없었다. 이는 비교 벤치마크 결과가 아니다.

## 아직 미정

- 개발 일정과 가용 시간, 최종 게임명·아트 스타일·목표 규모.
- 패키지 버전은 0-A에서 고정 완료했으며 미정 항목에서 제외한다. 실제 목록은 [Setup.md](Setup.md) 참조.
- 작업 소요 시간, 게임 내 하루 길이, 욕구 회복량·능력 저하 수치.
- 세부 경로 비용, 저장 포맷, 대규모 성능 목표.
- 전투 명중·제압·확률 규칙의 수치와 Fog of War의 세부 시야 알고리즘.

미정 사항은 필요한 작업 직전에 최소한으로 결정한다. 이전 결정 변경 시 이력을 지우지 말고 대체 결정과 이유를 추가한다.

## 2026-11-15 작업 0-A 적용 기록

- D12: 템플릿의 Domain Reload 생략 설정을 해제하고 Domain/Scene Reload를 모두 사용한다. 실행 간 상태 잔류를 줄이기 위해 초기 재현성을 우선했다. 향후 반복 속도 문제가 측정되면 재검토한다.
- 템플릿 패키지의 에디터 호환 갱신 결과를 그대로 고정했다. 빈 프로젝트에 불필요한 의존성 정리까지 확대하지 않았다.

## 2026-11-15 초기 월드 구현

- D17: B는 불변 seed와 읽기 전용 snapshot으로 시작한다. ID는 정착민·물자 전체에서 고유하며 개체 ID와 장애물 좌표를 정규 순서로 반환한다. 잘못된 시나리오는 오류 코드가 있는 예외로 거부한다. 상세는 [계약](Contracts/InitialWorld.md).

## 2026-11-15 최초 Git 기준점

사용자가 공유 폴더 유지, Git 초기화 및 현재 검증된 상태의 최초 기준 커밋 1회를 승인했다. main을 사용하며 기존 설정된 Git 작성자 정보를 유지한다. 원격을 등록하지 않으며 push하지 않는다. 이후 커밋에는 매번 새로운 승인이 필요하다. 생성 캐시와 원본 로그는 제외하고 제품 코드·설정·문서·검증 요약을 포함한다.
