# 정착민 이동·시간 조작 데모

작업 1 실행 안내. 2026-11-15 사용자가 이동·시간 조작에 대해 “모두 정상”으로 확인했다고 보고했다. 확인 환경의 상세 수치나 추가 로그는 별도로 제공받지 않았다.

## 실행 파일과 현재 범위

E:\Dev\RimworldTweak\Builds\Windows\RimworldTweak.exe

PowerShell에서는 프로젝트 루트에서 `& '.\Builds\Windows\RimworldTweak.exe'`로 실행한다. 배포할 때 exe 하나가 아닌 Windows 폴더 전체를 복사한다. 에디터는 Assets/Game/Scenes/SimulationSandbox.unity에서 Play한다.

8×8 맵과 정착민 3명, 목재40·식사18이다. 정착민을 선택해 목적지를 지정하고 4방향으로 한 칸당 5 Tick에 이동한다. 이동 외 생활·생산·전투·Fog of War·저장은 없다. 자원은 지나갈 수 있지만 줍거나 소비하지 않는다. 정착민 겹침은 이번 규칙상 허용한다.

## 조작

| 조작 | 결과 |
|---|---|
| 삼각형/오른쪽 정착민 목록 좌클릭 | 한 명 선택. 겹친 타일은 가장 작은 ID, 다른 사람은 목록 선택 |
| 선택 후 맵 우클릭 | 목적지 이동 예약. 다음 Tick에 적용 |
| 빈 타일 좌클릭 / Esc | 선택 해제, 기존 이동 유지 |
| Stop / X | 다음 Tick에 현재 타일에서 중지 |
| Pause/Resume / Space | 정지 또는 마지막 배속으로 재개 |
| 1×/3× / 숫자1/3 | 배속 변경과 재개 |
| Step +1 / 마침표 | 정지 중 정확히1 Tick. 5회면 한 칸 |
| Reset | 초기 위치·Tick0·명령/경로/선택 제거. 정지 여부·배속 유지 |

황금 테두리는 선택과 활성 목적지, 청록색 점은 남은 경로, 보라색 테두리는 아직 적용되지 않은 예약 목적지다. 정지 중에는 Pending만 표시되고 움직이지 않는다. 경로는 명령이 적용된 뒤 표시한다. 이동 중 다른 목적지를 지정하면 현재 타일에서 경로를 바꾸며 한 칸의 진행을 처음부터 센다. 같은 목적지 반복 지정은 진행을 유지한다.

장애물이나 접근 불가 목적지 명령은 이유를 표시하고 이전 유효 명령을 유지한다. 건설/장애물 편집 UI는 없다. 통행 변경에 따른 우회·대기·재개는 시뮬레이션/자동 검사에서 검증하는 기반 기능이다.

## 직접 확인할 6단계 — 사용자 정상 확인 보고

1. 실행 후 Pause. 목록의 Colonist 1 선택 → (5,1) 우클릭. Pending 목적지 표시, Tick과 위치는 그대로여야 한다. 맵 좌표는 왼쪽 아래가 (0,0)이다.
2. Step +1을 5번 누르면 한 칸, 총20번이면 (5,1)에 도착한다. 시작 지점에서 두 번째 정착민 타일을 지나며 겹침은 정상이다.
3. 다른 목적지를 지정하고 1×/3× 버튼과 숫자1/3, Space를 사용한다. 배속 표시·이동 속도가 맞고 Pause에서는 멈춰야 한다.
4. 장애물 (3,3)을 목적지로 지정하면 거부 이유가 보인다. (3,3)을 통과해야 할 직선 이동은 우회한다. 이동 중 다른 목적지와 Stop/X를 시험하고, UI 위 우클릭은 맵 이동을 만들지 않는지 확인한다.
5. 빈 타일/Esc로 선택을 해제해도 이동은 유지된다. 겹친 정착민은 목록으로 각각 선택한다. 한 입력에 한 번만 반응해야 한다.
6. 이동·정지 상태에서 Reset을 반복한다. 초기 배치, Tick0, 경로/선택 제거, pause/배속 유지와 창 크기 변경 시 글자·버튼·클릭 위치를 확인하고 종료한다.

확인 후 “모두 정상” 또는 “Space를 눌러도 이동함”, “목적지 클릭 좌표가 한 칸 어긋남”처럼 알려준다. 가능하면 해상도와 재현 순서를 덧붙인다. 자동 검사와 실제 사람 확인을 구분해 검증 기록을 갱신한다.

## 자동 실행

`pwsh -NoProfile -File Tools/Run-Demo.ps1 -Action Smoke`는 실제 창을 잠시 띄우고 정확 Tick·이동·배속·통행재개·반복 Reset·PNG를 검사한 뒤 종료한다. 일반 실행에는 자동 종료가 없다. 자동 검사는 UI 이벤트 경로를 검사하지만 OS 입력을 주입하지 않고 실제 사람의 클릭·체감을 대신하지 않는다.

후속 상태: 최신 실행 파일에는 자동 생활이 추가되어 생활 중 이동/Stop이 제한된다. 현재 조작은 [생활 데모](LivingDemo.md)를 따른다. 이 문서는 이전 이동 데모의 검증 맥락으로 보존한다.
