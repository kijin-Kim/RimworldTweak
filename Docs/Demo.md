# Windows 데모 실행과 수동 확인

이 문서는 작업 0 당시의 확인 기록이다. 현재 이동·시간 확장 실행 방법은 [새 데모 안내](MovementDemo.md)를 따른다.

대상: 0-C/D/E2/F. 2026-11-15 사용자가 아래 기존 데모를 “모두 정상”으로 확인했다고 보고했다. 확인 환경의 상세 해상도·로그는 별도로 받지 않았다. 자동 테스트의 버튼 이벤트 직접 호출은 마우스 클릭 검증을 대신하지 않는다.

## 실행

빌드 후 프로젝트 루트에서 다음을 실행한다.

```powershell
& '.\Builds\Windows\RimworldTweak.exe'
```

배포할 때는 exe 하나가 아니라 Builds/Windows 폴더 전체를 함께 복사한다. Unity 에디터에서는 Assets/Game/Scenes/SimulationSandbox.unity를 열고 Play한다. 컴파일과 패키지 가져오기가 끝난 뒤 실행한다.

1280×800 창을 기준으로 만든 임시 화면이다. 상단 이름과 설명, 왼쪽 맵, 오른쪽 Tick·상태·버튼·범례·자원 합계를 확인한다. 지도 좌표는 왼쪽 아래 (0,0) 기준이다.

## 수동 체크리스트 — 사용자 정상 확인 보고

- [x] 일반 실행에서 창이 열리고 글자·버튼·맵이 잘리지 않는다.
- [x] 8×8 맵에서 정착민 삼각형 3개: (1,1), (2,1), (1,2).
- [x] (4,1)의 목재 사각형 40, (4,2)의 식사 사각형 18. 오른쪽 합계도 목재 40, 식사 18.
- [x] (3,3)의 장애물은 다른 빈 타일보다 어둡다.
- [x] RUNNING에서 Tick이 증가하고 Step +1이 비활성이다.
- [x] 마우스로 Pause를 클릭하면 PAUSED로 바뀌고 Tick이 멈춘다.
- [x] Step +1을 한 번 클릭할 때마다 Tick이 정확히 1 증가한다.
- [x] Reset을 클릭하면 Tick이 0, 배치·수량이 초기값으로 돌아간다. 정지 상태는 유지한다.
- [x] Reset을 10회 반복해도 표시가 겹치거나 버튼 한 번에 여러 동작이 발생하지 않는다.
- [x] Resume을 클릭하면 Tick이 다시 진행된다. 진행 중 Reset은 초기 상태에서 곧바로 진행을 재개한다.
- [x] 창 크기를 바꿔 가독성과 버튼 클릭을 확인한다. 극단적 가로세로 비율은 별도 대응 범위다.
- [x] 창 닫기 또는 Alt+F4로 정상 종료한다. 다시 실행하면 초기 상태에서 시작한다.

확인 시 날짜, 실행 파일 기준(build-provenance.json), 해상도, 실패 항목과 재현 순서를 검증 기록에 추가한다.

## 자동 smoke와 차이

```powershell
pwsh -NoProfile -File Tools/Run-Demo.ps1 -Action Smoke
```

자동 smoke는 전용 인자로 실행되어 스스로 검사한 뒤 종료한다. 일반 실행에는 자동 검사나 강제 종료가 활성화되지 않는다. 자동화는 실제 Windows Player를 구동하고 상태·표시 개수·버튼 리스너 호출을 검사하며 PNG를 남긴다. Computer Use, 마우스·키보드 주입, 데스크톱 UI 자동화는 사용하지 않는다.
