# 정착지 운영과 기본 전투 요구사항

**진행 갱신** 아래 장착 1~5, 작업 1~3, 구조 1~4의 구현이 승인됐다. 새 정착지는 미장착으로 시작하며 소총·칼을 바닥에 제공한다. 아래 표에서 공통 사거리 4와 피해 25는 장착 시스템 도입 전 기준이며 기존 회차의 호환 동작이다. [구현 계획과 검토 결과](Settlement-Commands-Implementation.md) · [최신 검증 상태](../Status.md)

2026-11-19. [원작 비교 보고서](../Reviews/RimWorld-Gameplay-Comparison.md)에서 확인한 차이를 우리 게임의 판정 기준으로 옮겼다. **확정**은 사용자가 정한 동작, **현재 기준**은 통합 작업본에서 유지할 동작, **제안**은 채택 여부를 결정할 신규 규칙이다. 제안의 합격 예시는 구현 후 확인할 결과다.

## 1. 현재 유지할 규칙

| 구분 | 조건과 입력 | 관찰할 결과 |
|---|---|---|
| 현재 기준 · 시작과 시간 | 새 정착지를 열고 시간을 멈춘 뒤 정착민을 선택한다. | 250×250 지도 중앙의 세 정착민을 확인할 수 있다. 일시정지 중 선택·명령은 가능하고 이동·작업·피해는 틱이 진행될 때 반영된다. |
| 현재 기준 · 자율 작업 | 정착민별로 채집·운반·건설·농사·조리·치료를 끔 또는 1~3으로 설정한다. | 끈 직종은 자율 선택에서 빠진다. 실행 가능한 후보 중 낮은 숫자가 먼저다. 같은 숫자에서는 치료가 우선이며 그 밖의 후보는 거리·요청 순서 등 기존 동률 규칙을 따른다. |
| 현재 기준 · 생활과 자원 | 식사나 휴식이 필요한 정착민, 운반할 물자가 있는 정착지를 진행한다. | 정착민은 식사·휴식을 수행한다. 운반은 허용 품목을 받는 저장 구역을 사용하고, 같은 물자를 두 사람이 중복 소비할 수 없다. |
| 현재 기준 · 건설·재배·조리 | 설계도에 목재를 공급하고 경작 구역의 파종을 허용한다. 조리대에서 담당자·재료 범위·반복 조건을 설정한다. | 자재와 작업이 충족되면 건물이 완성된다. 작물은 파종·성장·수확으로 이어진다. 조리대는 해당 계획서 조건에서 생산하며 재고 목표에 도달하면 추가 생산을 멈춘다. |
| 확정 · 습격 발동 | 일반 플레이를 진행하거나 개발자 모드에서 일반 습격을 한 번 실행한다. | 일반 플레이에서는 자연 발생하지 않는다. 개발 명령은 조리대 선택이나 예고 없이 현재 월드에서 즉시 교전을 시작한다. 활성 회차에 다시 누르면 적이나 회차가 추가되지 않는다. |
| 확정 · 적 표적 | 출현 시 가까운 정착민 A를 고른 뒤 B가 더 가까워진다. | A가 유효하면 거리 변화만으로 표적을 바꾸지 않는다. 생존한 적이 피해를 받으면 일정 확률로 현재 위치에서 다시 계산한다. A가 전투 불능이 되면 추첨 없이 유효한 표적을 다시 찾는다. |
| 현재 시험값 · 추첨과 동률 | 같은 틱에 같은 적이 두 번 맞거나, 같은 거리에 후보가 둘 있다. | 생존했다면 합산 피해에 대해 한 번만 추첨한다. 현재 확률은 30%, 거리는 가로·세로 칸 수의 합, 동률은 낮은 정착민 ID 우선이다. 적 두 명의 동쪽 출현은 시험 배치다. |
| 현재 기준 · 전투와 회복 | 소집한 정착민으로 적을 우클릭한다. 전투 후 부상자에게 치료 가능한 작업자와 의약품을 제공한다. | 현행 공통 사격은 사거리 4와 사선 통과를 요구하고 피해는 25다. HP 0은 전투 불능이다. 현장 치료 한 번은 의약품 1개를 사용해 체력을 최대 100까지 40 회복시킨다. |
| 현재 기준 · 정보와 복원 | 적 선택 → 교전 중 저장 → 같은 슬롯 불러오기를 수행한다. | 지도와 선택 카드에서 체력과 표적을 읽을 수 있다. 복원한 적 수·위치·표적·난수 진행이 저장 당시와 같고 다음 피격 결과가 연속 플레이와 일치한다. |

상세한 실패 조건과 기존 파일 호환은 [일반 습격 기획](DebugRaid.md), 현재 실행 증거는 [통합 검증](../Verification/2026-11-19-integrated-settlement-raid.md)을 따른다.

## 2. 무기 장착과 공격 요구사항 · 제안

대표 상황은 **정착민 A가 바닥의 소총을 집어 장착하고, B는 같은 소총을 가져갈 수 없으며, A의 장착 정보와 실제 사격 결과가 일치하는 것**이다.

| 번호 | 규칙 | 합격 예시 |
|---|---|---|
| 장착 1 | 전투 가능한 정착민 한 명을 선택하고 바닥 무기를 우클릭하면 장착 명령과 무기 이름을 표시한다. 소집 전후 모두 허용한다. 복수 선택에서는 한 자루의 소유자를 임의로 고르지 않는다. | 두 명을 선택하면 한 명을 선택하라는 이유가 보인다. 한 명으로 다시 선택하면 같은 무기에 명령할 수 있다. |
| 장착 2 | 명령을 수락하면 한 사람이 무기를 예약한다. 걸어가 무기가 있는 칸에 도착했을 때만 장착한다. 일시정지 중에는 예약까지 허용한다. | A와 B가 같은 무기에 명령하면 먼저 수락된 A만 예약한다. 도착 전에는 무기가 바닥에 보이고 A는 새 무기로 공격할 수 없다. |
| 장착 3 | 개인 무기 슬롯은 하나다. 교체 성공 시 기존 무기를 정착민 칸에 내려놓고 새 무기를 장착한다. 실패하면 기존 무기를 유지한다. 취소·전투 불능·접근 불가 시 예약을 해제한다. | A가 소총을 가진 채 칼을 집으면 칼 한 자루는 A에게, 소총 한 자루는 바닥에 있다. 도착 전 취소하면 소총은 A에게 있고 B가 칼을 예약할 수 있다. |
| 장착 4 | 공격은 장착 무기의 종류·사거리·피해·준비·대기 값을 읽는다. 사거리 밖이나 막힌 사선에서는 원거리 피해가 발생하지 않는다. 무기 교체로 이전 무기의 준비 중 공격이 발사되지 않아야 한다. | 시험용 기존 정의를 사용할 경우 소총은 열린 직선 12칸에서 발사 가능하고 13칸에서 피해 0이다. 칼은 인접 1칸에서만 공격할 수 있다. 두 결과를 선택 카드의 무기 이름과 대조한다. |
| 장착 5 | 바닥·예약·장착을 구분해 저장한다. 이전 형식의 교전 파일은 당시 공격 규칙으로 이어지게 한다. 새 게임의 무기 공급은 아래 결정에 따른다. | 줍기 직전과 교체 직후 각각 저장·복원한다. 같은 입력으로 진행했을 때 소유자·바닥 수량·첫 피해 틱이 연속 실행과 일치한다. |

현행 사거리 4·피해 25와 독립 소총 정의 사거리 12·피해 20은 서로 다른 실행 경로다. 장착 4를 채택하면 새 회차의 판정 기준이 달라진다. 소총·칼을 첫 비교 대상으로 제안하며 카빈 추가와 최종 밸런스는 별도 결정이다. [무기별 시험 정의](../../Assets/Game/Simulation/EquipmentRules.cs) · [현행 교전 판정](../../Assets/Game/Simulation/WorldState.Combat.cs)

## 3. 개인 우선 작업 요구사항 · 제안

| 번호 | 규칙 | 합격 예시 |
|---|---|---|
| 작업 1 | 미소집·활동 가능 정착민 한 명으로 지정된 나무, 미완성 설계도, 수리 지정 시설을 우클릭하면 해당 일을 먼저 수행하는 명령을 표시한다. | A에게 벌목을 지시해도 B의 작업표와 정착지의 벌목 지정은 바뀌지 않는다. |
| 작업 2 | 우선 명령은 가능한 일의 순서만 바꾼다. 직종 끔, 긴급한 생존 욕구, 재료 부족, 다른 사람의 점유, 경로 단절을 무시하지 않는다. 거절 시 이유를 표시하고 기존 일을 유지한다. | B가 이미 목재를 점유한 설계도에 A를 보내도 B의 자재가 풀리거나 복제되지 않는다. |
| 작업 3 | 개인 우선 작업은 한 번에 하나다. 새 명령이 유효할 때 기존 일을 안전하게 중단한다. 완료·취소·소집 시 개인 지시를 지우고, 소집 해제 후 가능한 자율 작업을 다시 고른다. | 운반 도중 지시를 바꾸고 다시 소집해도 바닥·운반·시설에 있는 목재 총량이 같다. 진행 중 저장을 복원하면 담당자와 대상이 일치한다. |

## 4. 구조와 현장 치료 요구사항 · 제안

| 번호 | 규칙 | 합격 예시 |
|---|---|---|
| 구조 1 | 활동 가능한 미소집 동료를 선택해 전투 불능 아군을 우클릭하면 구조할 수 있다. 접근 가능한 빈 침대 하나와 환자 한 명을 함께 예약한다. | 빈 침대가 없으면 이유를 표시하고 환자는 제자리에 남는다. 두 구조자가 동시에 같은 환자를 가져갈 수 없다. |
| 구조 2 | 환자에게 도착하면 함께 이동하고 침대 도착 시 인계한다. 구조 자체는 체력을 올리거나 의약품을 사용하지 않는다. | 운반 중 환자가 혼자 이동하거나 바닥과 침대 양쪽에 표시되지 않는다. 침대 도착 직전과 직후 HP가 같다. |
| 구조 3 | 구조자 소집·전투 불능, 침대 상실, 명령 취소로 중단되면 환자를 현재 유효한 칸에 두고 예약을 해제한다. 운반 상태와 인계 결과는 저장한다. | 이동 중 저장 후 복원해 같은 칸에서 취소하면 환자가 한 명만 남고 다른 구조자가 이어받을 수 있다. |
| 구조 4 | 기존 현장 치료를 유지한다. 구조·치료 중 한 작업자만 환자를 점유하며, 인계 후 치료자가 침대의 환자를 치료할 수 있다. | 침대 없는 상황에서도 현행 치료가 가능하다. 구조 직후 치료를 시작하면 구조와 치료가 의약품을 각각 차감하는 일이 없다. |

## 5. 후속 후보의 채택 기준

아래는 원작 비교에서 나온 후속 선택지다. 사용자 선택 전에는 이번 구현 범위에 넣지 않는다.

| 후보 | 채택한다면 충족할 최소 규칙 |
|---|---|
| 중간 배속 | 2키와 화면 버튼이 같은 배속을 선택하고 시간 표시가 일치한다. 같은 시뮬레이션 틱에서는 작업·교전 결과가 배속과 무관하다. |
| 창고 우선순위 | 동일 품목을 받는 두 구역 중 접근 가능하고 빈칸이 있는 높은 우선순위 구역을 먼저 쓴다. 그 구역이 가득 차면 낮은 구역에 운반한다. |
| 작물 선택 | 경작 구역별로 다음 파종 품종을 지정한다. 기존 작물을 수확한 뒤 새 품종을 심고, 품종 선택과 성장 상태가 저장된다. |
| 엄폐·자유 사격 | 완전히 막힌 사선은 공격을 중지한다. 같은 사거리에서 부분 엄폐만 바꾸면 채택한 엄폐 규칙이 실제 판정에 반영된다. 자유 사격을 끄면 새 자동 공격을 시작하지 않고 직접 지정 공격은 가능하다. |
| 건강 정보 | 선택한 인물의 현재 HP·전투 불능·치료 진행과 치료를 막는 이유가 실제 상태와 일치한다. 부위별 상처·출혈은 별도 기획 후 추가한다. |

시작지 선택, 일과표·개인 정책, 다품목 레시피·냉장, 진행 확정 저장은 후속 범위로 둔다. 습격의 주기·스토리텔러·공병·공성·접근로는 기존 보류 결정을 유지한다.

## 6. 먼저 결정할 것과 검증 방법

1. **첫 신규 범위**로 무기 장착부터 진행할지 결정한다. 기존 디버그 습격에서 준비 → 장착 → 공격 → 저장 복원을 한 번에 볼 수 있어서 권장한다. 개인 우선 작업과 구조는 각각 별도로 채택할 수 있다.
2. **새 정착지의 무장 상태**는 미장착으로 시작하고 소총 한 자루와 칼 한 자루를 바닥에 제공하는 안을 권장한다. 이 안에서는 맨손 원거리 공격을 거절하고 ‘원거리 무기 필요’를 표시한다. 기존 전원을 무장시켜 곧바로 싸우게 하는 대안도 있다. 맨손 근접 전투의 수치와 신규 유형은 이번 제안에서 보류한다.

채택 후 에이전트는 위 표의 정상·거절·경쟁·취소·저장 사례를 시뮬레이션에서 검사한다. 이어 최신 HUD의 실제 선택·우클릭 명령과 Windows Player에서 같은 결과를 확인한다. 사람의 확인 항목은 기본 줌에서 무기 소유자, 명령이 거절된 이유, 환자의 운반 여부가 쉽게 읽히는지다. 요구사항 작성 뒤 진행한 구현·검사는 [세 기능 검증 기록](../Verification/2026-11-19-settlement-commands.md)에서 확인한다.
