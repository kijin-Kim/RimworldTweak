# 정착민 선택·상황 메뉴·공격 지시 개선

## 1. 선택

이동 중인 정착민 한 명을 클릭하거나 같은 위치를 범위로 감싸면 화면에 보이는 정착민이 선택돼야 한다. 기본 선택에서는 Unity 이벤트 시스템의 픽셀 드래그 기준을 사용한다. 누른 뒤 손이 조금 흔들려 칸 경계를 넘어도 누른 칸을 선택한다. 채집·저장·경작 도구는 기존의 칸 단위 지정을 유지한다.

## 2. 상황 메뉴에서 일시정지

재생 중 대상의 우클릭 메뉴를 열고 Space를 누르면 메뉴와 선택이 유지되고 시간이 멈춰야 한다. 메뉴에서 한 번 선택한 명령이 정지 중 접수되고 재개 후 진행돼야 한다. 다른 단축키와 저장·문자 입력 중의 차단은 기존 규칙을 따른다.

## 3. 공격 지시 확인

개인 카드와 초상 행동에 사거리 밖, 사선 차단, 조준 진행, 재공격 대기를 현재 무기 판정에 맞춰 표시한다. 복수 공격 지시는 실제 수락 인원과 전체 인원을 알려준다. 정지 중에는 시간이 흐른 것처럼 진행량이 변하지 않아야 한다.

Unity에서 모의 포인터·단축키, 이동 보간과 선택, 실제 교전 상태와 HUD를 확인한다. 전체 EditMode·PlayMode 검사 후 Windows 빌드와 개인 명령·습격 Player 검사를 직렬 실행한다. 카메라 이동은 같은 배율에서 새 입력과 기존 입력을 비교할 수 있도록 현행 속도를 유지한다. 실제 마우스 감도 선호는 사람 확인 항목이다.

## 직접 확인 순서

1. 공유 폴더의 `Builds/Windows/RimworldTweak.exe`로 새 게임을 열고 정착민을 소집해 이동시킨다. 걷는 정착민의 화면 위치를 클릭하거나 드래그로 감싸면 같은 인물이 선택돼야 한다.
2. 시간이 흐르는 동안 나무를 우클릭하고 Space를 누른다. 상황 메뉴를 유지한 채 시간이 멈춰야 한다. 채집 지정을 선택한 뒤 Space로 재개하면 된다.
3. 교전 확인은 실행 파일에 `--development-ui`를 붙여 시작한다. 정착민 한 명으로 소총을 장착하고 소집한 뒤 F3에서 일반 습격을 발생시킨다. 사수와 미장착 동료를 선택하고 적을 우클릭하면 2명 중 1명 수락으로 표시된다. 사수만 선택하면 적과의 거리·사선과 전투 진행에 맞는 행동을 볼 수 있다.
