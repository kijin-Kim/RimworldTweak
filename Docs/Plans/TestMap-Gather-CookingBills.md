## 요구사항과 설계

새 정착지는 32×32. 기존 시작 인물·물자·침대에 더해 외곽 채집 대상을 제공한다. 이전 저장의 크기는 파일에서 복원한다.
채집 도구는 저장 구역처럼 사각형 드래그로 범위 안 남은 대상을 지정한다. 역방향, 한 칸, 빈 범위, UI 위 해제, 우클릭 취소를 다룬다.
조리대별 여러 계획서 추가·삭제·재정렬·일시중지, 횟수/목표 재고/계속 생산을 지원한다. 사용자 선택으로 작업자 지정, 재료 허용과 탐색 거리, 완성품 운반 위치까지 포함한다.
현재 재료 종류는 Ingredients 하나이므로 허용 설정도 실제 지원 재료를 대상으로 한다. 계획서 목록에서 수행 가능한 첫 항목을 선택한다. 진행 중 계획서의 상태는 다른 항목과 섞지 않는다. 제품 생성과 운반 목적지 지정, 실제 운반까지 연결한다.

## 구현 순서

1. 새 정착지 시험 맵과 드래그 채집 입력·미리보기 및 회귀 검사.
2. 조리 계획서 자료와 생산·재료·담당·운반 선택 연결. 변경/삭제 중 재료와 진행 처리.
3. 계획서 목록·상세 설정 UI와 기존 저장의 이전 및 새 저장 복원.
4. Unity 검사, Windows 빌드와 Player 검증, 실제 조작 확인 절차.
