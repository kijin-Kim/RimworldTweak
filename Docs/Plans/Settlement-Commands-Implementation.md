# 장착·개인 작업·구조 구현 계획

## 1. 핵심 설계

새 정착지는 미장착 세 명과 바닥 소총·칼로 시작한다. 기존 저장은 그 회차의 공격 규칙을 유지한다. 한 정착민이 한 가지 직접 지시를 수행한다. 새 지시가 유효한지 먼저 확인하고 기존 지시를 교체한다. 같은 대상이나 침대의 중복 예약을 막고, 중단 때 이미 옮긴 물자와 환자 위치를 보존한다.

## 2. 동작과 구현 순서

1. 무기 한 자루를 예약하고 이동·장착·교체한다. 실제 공격에서 장착 정의를 사용하고 저장 복원 시 바닥·소유·예약의 유일성을 확인한다.
2. 기존 작업 후보와 시작·취소 처리를 사용해 선택한 사람에게 지정된 나무·설계도·수리를 한 번 맡긴다. 거절하면 현재 행동을 유지한다.
3. 부상자의 기존 치료 점유와 빈 침대를 함께 확인해 구조한다. 환자와 이동한 뒤 침대에 인계한다. 중단 시 현재 칸에서 풀고 체력과 의약품은 치료만 변경한다.
4. 위 순서로 월드 명령을 통합한 후 지도 우클릭·선택 카드·지도 표시·저장을 연결한다.

## 3. 완료조건과 검증

[세 기능 요구사항](Settlement-Gameplay-Requirements.md)의 장착 1~5, 작업 1~3, 구조 1~4를 판정 기준으로 한다. 각 기능에서 정상·거절·예약 경쟁·중단·중간 저장 재개를 규칙 검사로 확인한다. 실제 HUD와 Windows Player에서 명령 입력 → 월드 변화 → 저장 후 재개를 확인한다. 과거 저장과 기존 정착지 기능은 전체 EditMode·PlayMode와 빌드로 검사한다. 사람 조작의 가독성 판단은 Player 자동 검사와 구분한다.

## 4. 작업 소유권

장착 담당은 장비·공격, 작업 담당은 우선 작업, 구조 담당은 환자·침대와 각각의 저장 부분 및 기능 검사에 책임진다. 공통 월드·저장 접점, UI, 매니페스트, Windows 검사와 문서는 통합 담당이 관리한다. 같은 프로젝트에서 Unity 검사는 한 명이 직렬 실행한다.

## 5. 검토에서 반영한 변경

- 장착 담당은 소총의 준비·대기 시간이 구형 저장 검사 상한을 넘는 점을 확인했다. 장비를 쓰는 새 시나리오는 저장에 명시하고, 복원은 실제 장착 무기의 상한을 검사한다.
- 작업 담당은 재료 전달이 끝나도 시공과 수리가 남는 점을 확인했다. 우선 지시는 대상 시설 ID에 연결해 여러 단계 동안 유지하고, 다른 사람의 전달 예약까지 검사한다.
- 구조 담당은 침대 점유를 수면 전용으로 처리하는 기존 복원 검사를 확인했다. 실제 침대를 예약하고 환자 점유와 함께 검증한다. 구조와 치료는 같은 환자를 동시에 소유할 수 없다.
- 세 의견을 종합해 공통 중단은 직접 명령의 권한이 바뀔 때 적용한다. 내부 작업 단계 사이의 정상적인 종료가 개인 우선 지시를 잃게 하지 않는다. 판단·이동·도착·피해·저장 순서를 통합 담당이 연결한다.

실행 결과와 단계별 합격 근거는 [장착·개인 작업·구조 검증](../Verification/2026-11-19-settlement-commands.md)을 따른다.
