## 진행 순서와 검증

조리 목록 → 연속 도구/작업표 → 단축키/카메라 → 초상/알림과 선택 조작을 기능 단위로 구현한다. 각 변경은 실제 입력 경로와 대상 상태를 검사한다.32×32 시작 맵과 작은 화면에서 렌더를 확인하고 Windows 빌드/Player 검사와 기존 저장 회귀를 수행한다. 새 규칙은 해당 문서에 기록하고 자동 검사·진단 이미지·사람 확인을 구분한다.
아래는 단계별 이력이다. 최신 완료 판정과 근거는 [최종 검증](../Verification/2026-11-18-ui-experience.md)을 따른다.


## 구현 진행

조리 계획서 행에 수량/반복/중지/순서/삭제를 배치하고 상세 조건을 접는 형태로 개선했다. PlayMode109/109(20261118T010627540Z-e6c32eab). 기존 개별 설정 검사는 상세 열기를 명시해 계속 검증한다.
Tab/F1/쉼표/마침표 단축키와 방향키/Shift 이동, PageUp/PageDown 확대를 연결했다. PlayMode110/110(20261118T010817177Z-b32624c9). 추가 검사는 정착민 순환과 메뉴 중 차단을 확인한다. 실제 방향키·페이지키 입력과 렌더 검증은 후속이다.
새 이동 키도 포커스 복귀 후 놓기 전까지 억제하도록 보완했다. 이 마지막 보완은 다음 검사에 포함한다.
연속 도구, 작업표 역순 수정, 상태 표시·알림·복수 선택은 아직 남아 있다. Windows 빌드와 새 화면 수락은 전체 연결 후 진행한다.


### 연속 지정과 복수 선택

연속 건설/구역 지정과 실패 후 도구 유지, 우클릭/Esc 종료를 구현했다. 기존 성공 후 자동 선택/도구 종료 검사는 최신 UI 규칙에 맞춰 명시적 선택으로 변경했다. 작업표는 우클릭 역순0~3 변경을 지원한다.
일반 선택 모드의 드래그가 정착민 복수 선택을 수행하고 Shift 추가/제거, 전체 소집/해제, 선택 전원 이동을 기존 명령으로 연결했다. 각각의 선택 테두리와 드래그 범위를 표시한다. 현재 그룹 이동은 각 정착민에게 같은 목적 칸의 기존 이동 명령을 보낸다. 별도 대형/충돌 회피 배치는 구현하지 않았다.
초상에 포만도/휴식 막대, 행동과 수치 툴팁을 표시한다. 정상 목표 달성은 문제 알림에서 제외하고 대상 상세에서 조회한다.
PlayMode112/112 통과(20261118T011614254Z-3c8c2fb2). 연속 지정/역순 수정, 그룹 선택·소집·명령 수와 취소, 기존 UI/조리/저장 회귀를 포함한다.
아직 실제 카메라 키 입력의 세부 검사, 대상 상황 메뉴, 조리3행/복수 선택/새 초상의 작은 화면 렌더, Windows 빌드와 Player 검증 및 사람 수락은 남아 있다.
