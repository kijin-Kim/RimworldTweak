# 개선된 UI 확인 안내

실행 파일: `E:\Dev\RimworldTweak\Builds\Windows\RimworldTweak.exe`

표시와 정보 배치를 개선했다. 설정 명령은 다음 Tick에 적용한다. 새 UI의 실제 사람 조작 확인용이다. 자동 검사와 렌더 확인은 [검증 기록](Verification/2026-11-15-readable-ui.md)을 따른다.

## 화면 구성

- 상단: 색상과 번호가 고정된 정착민 목록, 정지/재개, 한 Tick, 배속, 초기화.
- 맵: 사람·나무·식물·식사 접시·식재료 바구니·통나무·침대를 서로 다른 모양과 이름으로 표시한다. 정착민 이름은 항상 보이며 R 소집 배지가 별도로 붙는다.
- 저장 구역: 반투명 바닥색과 구역 외곽선. 내부에는 칸별 큰 테두리나 상시 `0/50` 표시를 넣지 않는다. 선택한 칸의 용량과 점유자는 오른쪽 정보에 표시한다.
- 오른쪽: 채집/저장 도구, 같은 칸의 오브젝트 선택, 구역 필터, 미보관/운반/보관/총량.
- 하단: 선택한 정착민의 행동·대기 이유, 실제 운반물, 목적지, 점유 대상, 포만도/휴식도, 소집 버튼. 물자·침대를 선택하면 해당 오브젝트 정보를 표시한다.

## 직접 확인할 5단계

1. 세 정착민의 색과 `1 · 정착민` 등 이름이 맵과 상단 목록에서 일치하는지 확인한다. 이동·소집 중에도 고유 색상과 이름이 유지되어야 한다.
2. `채집 지정` 후 나무·식물을 클릭하고, `저장 구역`으로 빈 타일 사각형의 두 모서리를 클릭한다. Esc 또는 우클릭으로 도구를 해제한다. 바닥색과 외곽선이 구역을 표시하고 사람·물자 모양을 가리지 않아야 한다.
3. 운반 중인 정착민을 선택한다. 하단의 운반 종류·수량, 목적지 좌표, 점유 대상이 물자 집기 전후로 바뀌는지 확인한다. `위치 보기`는 맵 안의 점유 대상 테두리를 강조하고 `점유 대상 선택`은 대상 정보를 연다. 상단 정착민 버튼으로 다시 돌아올 수 있다.
4. 정지 후 R을 누른다. 하단 행동은 소집 대기, 운반물과 점유 대상은 없음으로 바뀌고 바닥에 물자가 남아야 한다. 해제 후 식사·수면·채집·운반이 재선택될 때 하단 표시도 따라 바뀌어야 한다.
5. 물자가 겹친 타일을 클릭하고 `다음 오브젝트`로 각각의 이름·수량·점유자를 확인한다. 초기화 후 이름 중복이나 이전 대상 강조·구역이 남지 않아야 한다.

정상이라면 “모두 정상”이라고 알려주면 된다. 문제가 있으면 선택한 정착민 번호, 진행한 조작, 잘못 보인 항목을 알려주면 된다. 이 확인은 커밋 승인이 아니다.

## 범위와 한계

카메라 확대/축소·팬, 실제 정착민 개인 이름, 농사·조리·건설·전투·파일 저장은 추가하지 않았다. 현재 Windows 대상에서 시스템 한국어 글꼴을 사용한다. 다른 OS와 해상도의 실제 플레이 가독성은 별도 확인 대상이다. 색만으로 식별하지 않도록 번호·이름·모양을 함께 사용한다.
