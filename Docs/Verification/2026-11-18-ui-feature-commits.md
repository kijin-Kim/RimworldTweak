# UI 기능별 커밋 검토

사용자가 2026-11-18 UI 작업의 변경 검토와 기능별 커밋을 승인했다. 원래 detached HEAD d0069af에서 이미 존재하는 검증된 저장 기준 37b457a로 인덱스를 맞췄으며 작업 파일은 보존했다.

## 기능 구분

1. 교체 가능한 아트와 월드 지도 표시·입력, 읽기 전용 배치 판정
2. 이름 있는 저장 슬롯·설정 및 파일 실패 보존
3. 건축가·HUD·선택·작업표·메뉴 UI와 Player 검사·수락 기록

각 단계는 앞 단계에 의존한다. 전투 기획과 협업 지침, 과거 검증 문서의 로컬 차이, 일반 Unity 재직렬화는 이번 커밋 범위에서 제외한다. 신규 Assets와 meta는 함께 포함한다. 저장 기준 이후 제품 변경의 필수 연결을 확인하고 분리한 인덱스를 별도 검사 폴더에 내보내 검증한다.

## 검토 중 발견한 검사 불안정성

UI 통합 분리본의 20261117T232511559Z-a076c2bb 실행은 설정 재시도 검사가 실패했다. 두 번 오류를 주입한 뒤 마지막 실제 Windows 교체의 성공까지 단정한 것이 원인이다. 마지막 실제 호출도 1175이면 재시도 상한과 오류 코드·원본 보존을 검증하도록 수정했다. 성공하면 새 배율을 읽는 검사는 유지한다.

다음 20261117T232638604Z-512e20e1 실행은 무효 경로 검사에서 두 fixture가 같은 legacy 파일을 덮어쓰다가 실패했다. 경로 복원 검사의 두 입력을 서로 다른 파일에 저장하도록 해 파일 교체 검증과 분리했다. 제품의 파일 교체 정책은 유지한다. 두 테스트의 보완은 UI 통합 커밋에 포함한다. 이 실패 기록과 각 재검사 결과를 함께 보존한다.

실제 두 프로세스 재실행(20261117T233103440Z-ux-restart)은 같은 슬롯의 Tick 17 저장과 Tick 20 이동 완료, 후속 상태 해시 일치, 각 종료 0을 확인했다. 일반 창 PNG 두 장은 기존과 같이 단색으로 도구 종료 1이다. 실제 조작 수락은 사용자 전체 정상 확인 기록을 따른다.

원래 작업 파일의 해시 대조에서 검토 중 의도적으로 변경한 SaveRepositoryTests.cs와 SaveTests.cs 외 제품 입력 변경은 없었다. Docs/Status와 README는 UI 관련 내용만 인덱스에 구성하고, 작업 폴더의 다른 세션 내용은 보존했다. 전투 문서·협업 지침·과거 문서의 로컬 삭제·자동 생성 로그/실행 파일/검사 결과·로컬 RimWorld 참고 원본은 제외했다.

코드와 검사 텍스트의 줄끝 공백 검사는 통과했다. Unity가 생성한 meta/YAML의 기존 직렬화 공백은 보존했다. 승인 범위의 기능 변경은 세 커밋으로 저장하며 새 원격 연결이나 push는 하지 않는다.
