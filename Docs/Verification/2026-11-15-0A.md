## 로그의 별도 관찰 사항

로컬 원본 로그: `Logs/0A-create.log`, `Logs/0A-editor.log`. Logs는 .gitignore 대상이며 원본 로그에 로컬 계정·라이선스 정보가 있으므로 문서에 전체 복사하지 않았다.

- 기존 Hub 라이선스 클라이언트와의 프로토콜 handshake 재시도, 서명 validation 관련 메시지, access token unavailable 메시지가 있었다. 에디터 버전의 클라이언트 연결과 Unity Personal entitlement 확인은 성공했고 실행을 막지 않았다. 이 라이선스 환경 문제의 근본 해결을 완료한 것은 아니다.
- DX12 info queue 인터페이스 조회 실패 메시지가 있었으나 에디터 렌더링은 확인했다.
- 초기 가져오기에서 Terrain shader dependency not found 메시지가 있었다. 생성·GUI 로그에서 `Shader error`와 `Exception:`은 발견되지 않았고 현재 빈 2D 장면 Console은 0건이었다. Terrain 기능의 정상 동작을 입증하지 않는다.
- 생성 종료 과정의 Curl error 42가 있었으나 에디터는 return code 0으로 종료했다.
