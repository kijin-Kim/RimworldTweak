## 결론과 범위

정착민 선택·목적지 지정·4방향 이동·중지·재지정, 일시정지·1/3배속·단일 Tick, 통행 변경에 따른 우회·대기·재개와 초기화를 구현했다. 자동 검사와 Windows 빌드·실행·렌더 이미지 검토 완료. 새 조작의 사람 확인은 미검증이며 [실행 안내](../MovementDemo.md)에 6단계 확인을 제공한다. 기존 데모의 사용자 정상 확인을 새 기능 통과로 사용하지 않는다.

기존 8×8·정착민3·목재40/식사18 유지. 생활·생산·전투·저장·FoW·다중 선택·충돌 회피·대각 이동·부드러운 보간은 없다. 통행 변경은 시뮬레이션 명령과 검사에서 지원하며 사용자용 벽 편집 UI는 없다.

기존 초기 상태15·시간6·PlayMode5 검사 의미를 보존하고 이동 EditMode12·PlayMode8을 추가했다. WorldState.Colonists 타입 변경에 맞춰 readonly 검사를 적응했고, long.MaxValue를 실제 Tick 반복하는 대신 테스트 내부 Reflection으로 경계값을 설정하여 overflow 시 명령 미소비와 상태 보존을 검사했다. 제품용 테스트 우회 API는 만들지 않았다.

## 실패·보완과 병렬 검토

[교차 검토 기록](../Reviews/2026-11-15-movement-review.md) 참조. 공통 계약 선확정 후 Simulation/Presentation/Tests는 서로 다른 담당자가 병렬 작성, Runtime/통합은 root 담당. 모든 Unity 실행은 작성 동결 후 root가 직렬 실행했다.

첫 실행 20261115T073120671Z-b61361c6은 NUnit 컬렉션 표현식 컴파일 오류로 실패했다. Has.No.Member로 고쳐 동일 의미를 유지한 후 통과했다. 첫 성공 렌더에서 경로 점의 수량 가림을 발견하고 표시만 수정한 뒤 최종 검사를 재실행했다. 실패 기록은 삭제하거나 성공으로 덮어쓰지 않았다.

## 미검증·한계

- 새로운 기능의 실제 마우스/키보드 조작, 창 크기별 가독성·배속 체감은 사용자 확인 전이다. PlayMode는 엔진 내 이벤트 호출과 좌표 검사이며 OS 입력 자동화가 아니다.
- Player 종료에 기존 ComputeBuffer 정리와 D3D12 4096-byte 리소스 해제 경고가 남는다. UI 객체수 안정성과 정상 종료는 확인했으나 GPU 메모리 누수 없음이나 엔진 원인은 확정하지 않았다. 장시간 프로파일링 미실행.
- 경로·화면은 현재8×8·3명 기준. 큰 맵·수백명 성능이나 다른 GPU/OS는 미검증이다. 프레임당 Tick 예산 없이 입력 Tick을 모두 처리하므로 규모 확장은 별도 측정과 설계가 필요하다.
- Computer Use·커밋·원격 연결·push 없음. 공유 폴더와 기준 커밋784f242 유지, 모든 후속 변경은 미커밋.

## 후속 사용자 확인 — 2026-11-15

사용자가 이동·시간 조작에 대해 “모두 정상으로 확인했어”라고 보고했다. 위 미검증 표기는 자동 검증 종료 시점의 기록이며 새 조작의 사용자 확인 상태를 갱신했다. 확인 환경 상세 수치·추가 로그는 받지 않았고 에이전트가 OS 입력을 실행했다는 의미는 아니다. 기존 그래픽 리소스 경고 원인과 장시간 프로파일링 미실행 상태는 이 보고만으로 해결 처리하지 않는다. 다음 생활 기능은 아직 계획 단계다.
