## 원인과 변경

- World.QueueMove는 대기 중인 미소집 Pawn도 수동 이동을 접수했다. 과거 계획의 이 규칙을 최신 사용자 지시에 맞춰 폐기했다. 이제 소집 여부를 접수/적용 단계에서 검사한다. 거부는 큐/예정 목적지/자동 행동/점유를 바꾸지 않는다. 소집 해제는 대기 중 이동도 지운다. 선택·자동 생활/작업의 내부 이동은 계속 가능하다.
- 건설 패널은 SelectedObjectId만 조회했다. Pawn을 선택하면 그의 실제 건설 대상이 연결되지 않아 패널을 열어도 안내만 보일 수 있었다. 이제 PendingDeliveryTargetId(반입 현장) 또는 WorkTargetId(시공/철거 대상)로 실제 현장을 조회한다. 선택한 Pawn이 건설을 시작하거나 다른 현장을 맡으면 패널이 열린다. 같은 현장에서 사용자가 물류 보기로 전환한 선택은 매 프레임 강제로 되돌리지 않는다.
- 출발 스택 접근/반입 이동/시공 동안 현장 이름·ID·반입 자재·시공 진행·담당을 표시한다. 실제 점유 대상과 반입할 현장은 구분한다. 정지 중에도 RefreshNow로 반영한다. 패널 취소/철거 버튼은 표시 중인 대상 ID를 사용한다.

## 직접 확인

실행 파일: `E:\Dev\RimworldTweak\Builds\Windows\RimworldTweak.exe`.

1. Space로 정지하고 미소집 정착민을 선택한 뒤 빈 칸을 우클릭한다. 이동 예약이 생기지 않고 소집 안내가 표시되어야 한다.
2. R로 소집한 뒤 같은 칸을 우클릭한다. 이동 예약이 표시되며 재개하면 이동한다. 다시 정지하고 R로 해제하면 남은 수동 이동은 취소되어야 한다.
3. 건설/재배에서 침대를 지정하고 미소집 정착민이 목재를 반입하도록 재개한다. 작업자를 상단 목록에서 선택하면 별도로 현장을 클릭하지 않아도 오른쪽 패널과 하단 정보에 실제 현장·목재·시공 진행이 보여야 한다.
4. 시공 중 정지한다. 진행 수치는 멈춘 채 보이고 R로 소집하면 행동·점유가 즉시 해제된다. 현장 자재와 진행은 유지되어야 한다.

답변 예: “두 문제 모두 정상” 또는 “반입 중인 Pawn을 선택해도 건설 패널에 현장이 안 나옴”. 실제 사람의 조작 확인은 아직 수행하지 않았다. 조리/작업계획/파일 저장은 계속 미구현이다. 기존 Player 종료 ComputeBuffer/D3D12 경고는 이 수정과 별도로 남아 있다.
