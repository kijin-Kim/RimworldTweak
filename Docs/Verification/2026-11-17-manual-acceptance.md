# 저장·UI·아트 사람 확인 카드

상태: 2026-11-18 사용자 전체 확인 완료. 사용자가 직전 정상 창 및 M2~M4 확인 요청에 “전부확인했어”라고 회신했다. 이 회신은 확인 카드 전체의 정상 확인으로 기록한다. 자동 검증과 진단 렌더의 상세 근거는 [진행 기록](2026-11-17-save-ui-art-progress.md)과 [UI 구현 기록](../Plans/RimWorld-UI-Implementation.md)을 따른다.

대상 빌드: `20261117T160332515Z-build` (Windows 빌드 성공, 입력 변경 0). PlayMode 105/105(`20261117T160218908Z-362c6ff1`). 최신 UI 배치와 자동 검사 결과는 [UI 구현 기록](../Plans/RimWorld-UI-Implementation.md)을 따른다. 이전에 보류한 M1도 이번 전체 확인 회신에 포함해 기록한다.

## 실행

PowerShell에서 다음 명령을 실행한다. 일반 exe 직접 실행과 달리 전용 저장 폴더를 사용한다.

```powershell
pwsh -NoProfile -File "C:\Users\kijin\.codex\worktrees\rimworld-feature-b\RimworldTweak\Tools\Start-ManualCheck.ps1"
```

- 실행 파일: `C:\Users\kijin\.codex\worktrees\rimworld-feature-b\RimworldTweak\Builds\Windows\RimworldTweak.exe`
- 격리 저장/설정: `C:\Users\kijin\.codex\worktrees\rimworld-feature-b\RimworldTweak\TestResults\ManualAcceptance`
- 로그: 위 폴더의 `player-<실행시각>.log`
- 기본 창: 1280×720. 같은 명령을 다시 실행하면 같은 확인용 저장을 사용한다. 먼저 게임 메뉴에서 정상 종료한 뒤 재실행한다.
- 큰 화면 비교: 같은 명령 끝에 `-Width 1920 -Height 1080`을 붙인다. UI 배율은 게임의 화면 설정에서 바꾼다. 작은 화면 검사에는 150%, 큰 화면에는 100%를 사용한다.
- 이 스크립트는 사용자가 실행할 때 게임 창을 연다. 자동 클릭이나 자동 진행은 하지 않는다. 자동 검사 목적으로 창을 띄우는 승인을 대신하지 않는다.

## M1. 한글 이름·슬롯·재실행

1. 새 정착지를 시작하고 정지한다. 게임 화면과 한글 메뉴가 보이는지 확인한다. 검은 화면이면 여기서 멈추고 보고한다.
2. 메뉴 → 저장에서 기존 이름을 지우고 Windows 한글 IME로 이름을 입력한다. 조합 중 Esc/Enter를 각각 시험한다. 조합 취소/확정에 쓰인 키만으로 저장이나 메뉴 종료가 발생하면 실패다. 최종 이름을 `한글 확인 A`로 정리하고 새 슬롯에 저장한다.
3. 게임으로 돌아가 정착민 한 명을 소집하고 다른 칸으로 이동시킨 뒤 정지한다. `한글 확인 B`를 새 슬롯으로 저장한다. A와 B가 따로 표시돼야 한다.
4. A와 B를 차례로 불러온다. 확인창에는 대상 이름과 진행을 잃는다는 안내가 있어야 하며, 선택한 슬롯의 정착민 위치와 시간으로 돌아와야 한다. 한 번은 불러오기 확인을 취소해 현재 진행이 유지되는지도 본다.
5. B에서 저장 후 종료를 선택하고 B 덮어쓰기를 확인한다. 같은 실행 명령으로 재실행해 이어하기를 누른다. B의 진행이 복원돼야 한다. 설정 갱신 경고가 나타나면 문구를 기록하고 불러오기 목록에서 B를 직접 선택한다.

회신: `M1 정상` 또는 `M1: 조합 중 Enter를 누르자 저장 화면이 닫힘`처럼 실제 현상을 적는다. 정상 창 표시와 실제 IME는 이 결과가 있어야 확인 완료다.

## M2. 탐색·선택·UI 스크롤

1. 1280×720에서 화면 설정을 150%로 바꾼다. 메뉴가 잘리지 않고 돌아갈 수 있어야 한다.
2. 초상 클릭으로 선택하고 더블클릭으로 해당 정착민을 찾는다. 휠과 중간 버튼 드래그/WASD로 지도를 탐색한다. 가리킨 대상과 실제 선택이 맞아야 한다.
3. 작업 배분을 열고 그 위에서 휠을 굴린다. 표가 넘치면 마지막 행까지 이동할 수 있어야 하고, 모든 행이 보이면 표는 그대로일 수 있다. 두 경우 모두 지도 줌은 변하지 않아야 한다. 패널을 닫고 지도 위 휠이 줌을 바꾸는지도 확인한다.
4. 메뉴를 열었다 닫아 원래 정지/배속이 유지되는지 본다. 드래그 중 메뉴나 다른 창으로 전환했다 돌아와 마우스를 놓아도 구역이나 이동 명령이 생기면 안 된다.
5. 게임을 종료하고 1920×1080 실행 명령으로 다시 연다. 기본 배율 100%에서도 위 핵심 조작을 확인한다.

회신: `M2 정상` 또는 `M2: 작업표 위 휠로 지도도 확대됨`.

## M3. 건설·작업·구역

1. 조작 확인용 정착민의 소집을 해제하고 시간을 재개한다. 자동 작업이 가능한 상태에서 시작한다.
2. 건축가 → 생산 → 조리대를 선택해 빈 칸과 막힌 칸에 포인터를 올린다. 유효/불가 표시와 이유가 구분돼야 한다. 우클릭으로 취소하면 배치되지 않아야 한다.
3. 빈 칸에 조리대를 배치한다. 한 번 생성되고 도구가 해제돼야 한다. 완공 후 조리대 선택 → 요약 오른쪽의 조리 주문 타일을 눌러 상세를 펼친다. 가동/중지와 목표, 입력/진행/출력을 확인한다.
4. 작업 배분에서 조리 우선순위 숫자를 바꾸고 끔/켬을 시험한다. 숫자는 현재 진행을 유지하고 끔은 해당 담당을 해제해야 한다. 정지 중 설정과 표시는 바뀌되 시간이 진행되면 안 된다.
5. 건축가 → 구역에서 저장과 경작을 정방향·역방향·한 칸으로 지정한다. 놓은 범위가 한 번 생성돼야 한다. 드래그를 UI 위나 지도 밖에서 끝내면 생성되지 않아야 한다.
6. 저장 구역의 저장 필터 타일에서 필터를 바꾸고, 경작 구역의 파종 타일을 전환해 본다. 각 구역의 삭제 버튼도 확인한다. 표시와 결과가 일치해야 한다. 건설 설계도 취소와 철거 지정/해제도 한 번씩 확인한다.

회신: `M3 정상` 또는 `M3: 경작 구역을 UI 위에서 놓았는데 일부가 생성됨`.

## M4. 아트 식별·겹침·정지

1. 세 정착민을 이름과 색으로 구분하고 앞/뒤/옆 이동을 본다. 초상으로 선택한 정착민과 지도 대상이 일치해야 한다.
2. 목재·식재료·식사를 형태로 구분한다. 식재료는 채집/수확 후 확인할 수 있다. 경작지의 어린 작물·성장한 작물·성숙 작물을 성장 중 각각 관찰한다. 성장 대기는 3배속으로 줄일 수 있다. 아직 보지 못한 상태는 미확인으로 적는다.
3. 최소/기본/최대 줌에서 이름·수량·선택 표시를 읽고 나무 뒤 정착민을 선택한다. 그림의 발/밑면과 칸의 접점이 흔들리거나 선택 표시가 완전히 가려지면 기록한다.
4. 이동·운반·수면·작업 중 정지해 연출이 멈추는지 본다. 정지 중에도 UI 버튼과 호버는 반응해야 한다. 아직 발생하지 않은 행동은 별도 미확인으로 적는다.

회신: `M4 정상` 또는 `M4: 최소 줌에서 어린 작물 구분 어려움; 수면은 아직 미확인`.
