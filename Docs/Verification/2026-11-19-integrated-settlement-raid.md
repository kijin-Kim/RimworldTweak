# 250×250 정착지와 일반 습격 통합 검증

## 현재 작업본

`E:\Dev\RimworldTweak`의 `integration/latest-local`에서 계속 작업한다. 2026-11-19 확인한 로컬 main과 원격 main은 모두 `338697e`였다. 소스는 최신 main, UI 작업 폴더의 250×250 정착지·작업 애니메이션·저장 변경, 현재 폴더의 일반 습격·회복 변경, 전투 규칙 작업 폴더의 시야·장비 판정과 검사를 포함한다. 다른 작업 폴더 원본은 그대로 보존했다. 통합 전 파일 비교 자료는 `TestResults/integrate-20261119-161640`에 있다.

## 재현 절차

1. PowerShell에서 `& 'E:\Dev\RimworldTweak\Builds\Windows\RimworldTweak.exe' --development-ui`를 실행하고 **새 정착지**를 선택한다. 정착민 세 명이 지도의 중앙에서 시작한다.
2. 시간을 멈추고 **F3 → 일반 습격 발생**을 누른다. 시간이 멈춘 채 동쪽 끝에 적 두 명이 나타난다. 적의 체력과 표적 정착민 번호가 지도에 표시된다.
3. 적을 선택해 체력과 표적을 확인한다. 정착민 초상 → **소집** → 적 우클릭 순으로 공격을 지정한다. 정착민은 사거리와 시야를 만족할 때 발사한다.
4. **Esc → 저장**에서 이름을 지정한 후 불러온다. 새 적이 추가되지 않고 저장 당시 적과 표적이 복원된다. 시간을 재개하면 교전이 이어지고 결과가 알림에 표시된다.

일반 실행에서는 개발자 단축키가 비활성이다. 습격 시작은 정착민의 위치, 현재 틱, 진행 중인 월드를 초기화하지 않는다. 자동화는 게임 명령과 Player 렌더를 사용한다. 마우스·키보드의 실제 조작감은 직접 플레이에서 확인할 항목이다.

## 이전 저장과 판정 규칙

실제 UI 세션의 250×250, 28틱 저장을 새 작업본에서 읽어 정착지 크기를 확인하고 습격을 시작한 뒤 새 슬롯에서 적 두 명을 복원한다. 원본 저장 바이트도 비교한다. v1 정착지에는 새 체력·치료 상태의 초기값을 부여한다. 기존 조리대 회차와 일반 습격 회차의 저장 규칙, 피격 재선정 확률 경계와 난수 진행을 확인하는 별도 검사도 포함한다. 거리 동률은 낮은 정착민 ID가 우선이고, 실제 피해 후 재선정 확률은 시험값 30%다.
