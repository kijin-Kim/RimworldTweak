## 다음 필수 입력

사용자가 실행 카드의 M1~M4를 수행한 실제 결과가 필요하다. 우선 M1에서 정상 창 표시와 한글 조합을 확인한다. 실패가 있으면 해당 결과를 재현·수정·재검증하고, 통과하지 않은 항목은 그대로 남긴다. 최종 아트는 `IsFinalArt=false`를 유지한다. 사람 확인 없이 최종 채택으로 바꾸지 않는다.

Computer Use/데스크톱 UI 자동화 금지 지침을 유지한다. 합성 입력/진단 RenderTexture로 수동 확인을 대체하지 않는다. 커밋·원격 게시는 승인되지 않았다.
