# 장착·개인 작업·구조 검증

## 완료조건과 확인한 동작

| 요구사항 | 입력과 확인한 결과 |
|---|---|
| 장착 1·2 | 새 정착지에서 세 명 모두 미장착으로 시작한다. 한 명으로 바닥 소총을 우클릭하면 정지 중에도 예약된다. 도착 전까지 소총은 바닥에 있고 두 번째 정착민의 예약은 거절된다. |
| 장착 3 | 장착 직전 저장을 복원해 한 틱을 더 진행하면 같은 사람이 같은 소총을 얻는다. 칼을 가지러 가다가 취소하면 소총은 그대로다. 교체 완료 시 소총 한 자루만 바닥에 있고 칼 한 자루만 장착된다. 경로 차단과 전투 불능은 예약을 해제한다. |
| 장착 4·5 | 소총 사거리 12, 피해 20, 준비 20틱, 대기 30틱과 칼 사거리 1, 피해 8을 실제 공격으로 확인했다. 막힌 사선·사거리 밖·미장착을 구분한다. 조준 중 저장 뒤 연속 실행과 복원 실행을 비교하고 중복 무기 ID·잘못된 소유 기록은 거절한다. 구형 교전의 공통 사격 규칙을 유지한다. |
| 작업 1·2 | 지정한 나무와 설계도, 수리 지정 시설에서 선택한 작업자에게 일을 맡긴다. 다른 사람의 목재 배달이 시작됐지만 아직 시설 점유 전인 상황에서도 새 지시가 기존 배달을 가로채지 않는다. 직종 끔·긴급 욕구·막힌 경로·대상 미지정은 거절한다. |
| 작업 3 | 목재 여러 번 전달 → 시공 완료까지 같은 담당자를 유지한다. 저장을 복원해도 대상이 유지된다. 운반 중 지시 교체·소집 전후의 총 목재를 비교했고, 수리에 사용한 목재와 내구도 회복을 검사했다. |
| 구조 1 | 미소집 동료로 쓰러진 아군을 우클릭해 환자와 침대를 함께 예약한다. 다른 구조자, 빈 침대 없음, 막힌 경로와 이미 치료 중인 환자를 구분해 거절한다. |
| 구조 2·3 | 환자를 데리고 이동하다가 소집·취소·구조자 전투 불능·침대 파손 시 현 위치에 내려놓는다. 운반 중 저장과 침대 인계 후 저장을 복원해 환자 위치·침대 점유가 일치하는지 검사한다. |
| 구조 4 | 인계만으로 HP와 의약품이 바뀌지 않는다. 인계 후 치료가 가능하고 침대가 없는 상황의 기존 현장 치료도 가능하다. 구조와 치료가 동시에 같은 환자를 맡지 않는다. |

## 검사 방법

- 규칙 검사에서 새로 추가한 검사 15개와 기존 검사를 함께 실행한다. [장착 검사](../../Assets/Game/Tests/EditMode/Simulation/WeaponOrderTests.cs) · [작업 검사](../../Assets/Game/Tests/EditMode/Simulation/PriorityWorkTests.cs) · [구조 검사](../../Assets/Game/Tests/EditMode/Simulation/RescueCommandTests.cs)
- Windows Player의 `Tools/Run-UXCheck.ps1 -Action SettlementCommands`는 실제 새 250×250 정착지에서 소총을 우클릭해 장착하고 저장을 다시 연다. 우선 작업·구조 검사는 조건을 일정하게 맞추기 위해 쓰러진 환자, 빈 침대, 나무가 있는 작은 정착지 저장을 사용한다. 우선 벌목 도중 구조를 지시하고, 환자 운반 상태에서 슬롯을 불러와 침대까지 이동한다. 각 저장 시점의 전체 상태 해시가 복원 후에도 같아야 통과한다.
- `-Action RaidIntegration`은 새 정착지에서 소총을 장착한 뒤 습격을 발생시키고, 교전 중 저장·복원과 적 우클릭 공격에서 종료까지 확인한다. 모두 스크립트로 게임 명령을 넣은 Player 검증이다.

## 직접 확인

1. 일반 실행으로 새 정착지를 연다. 정착민 근처에 소총과 칼이 하나씩 보인다.
2. 시간을 멈추고 정착민 한 명을 선택한 뒤 소총 우클릭 → **소총 장착**을 누른다. 재개하면 무기까지 걸어가고, 바닥의 소총이 사라지면서 선택 카드에 **소총**이 표시된다.
3. 나무에 채집을 지정한다. 미소집 정착민을 선택해 나무를 우클릭하고 **벌목 우선 작업**을 누른다. 행동 표시에서 우선 지시를 확인하고 **지시 취소**로 중단할 수 있다.
4. 습격을 시험하려면 `--development-ui`로 실행하고 F3에서 일반 습격을 누른다. 전투 불능인 아군과 빈 침대가 있으면 미소집 동료로 아군을 우클릭해 **구조**를 지시한다. 운반 중인 환자는 동료와 함께 이동하며, 침대 인계 후 **침대에서 치료 대기**로 표시된다.
