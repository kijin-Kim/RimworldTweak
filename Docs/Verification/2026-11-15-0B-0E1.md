# 작업 0-B / 0-E1 검증 결과

날짜: 2026-11-15 (Asia/Seoul). 판정: **0-B 및 0-E1 통과**. 게임 화면·Tick·Play Mode 통합을 검증한 결과가 아니다.

## 계약과 병렬 작업

[초기 월드 계약](../Contracts/InitialWorld.md)을 먼저 확정하고 root가 공통 asmdef·폴더 meta를 배치했다.

- simulation_b: Simulation C# 6개와 해당 meta 구현.
- verification_e1: 독립 EditMode 검사 15개, 기대 검사 목록, CLI 실행기·판정기·판정기 자체 검사 구현.
- root: 계약·공유 파일, 구현 읽기 검토, 실제 Unity 실행, 문서 반영.

제품과 테스트는 계약을 기준으로 병렬 작성했다. simulation_b가 테스트를 추가 읽기 검토했고 root가 양쪽 코드를 확인했다. 각 담당의 완료·쓰기 동결 보고 후 실제 검사를 한 번 실행했다. Computer Use, Git 초기화, 커밋은 하지 않았다. 공유 파일 충돌과 계약 변경에 따른 재작업은 발생하지 않았다. static class에 붙일 수 없는 sealed 표현만 계약 문구에서 바로잡았다.

## 구현 결과

8×8 초기 맵, 장애물 (3,3), 정착민 3명, 목재 40·식사 18의 고정 초기 데이터를 제공한다. 입력 컬렉션과 요소를 복사하고 외부에는 읽기 전용 상태만 제공한다. 중복/잘못된 ID, 맵 밖 위치, 잘못된 수량·종류, null과 막힌 위치를 오류 코드로 거부한다. 개체는 ID, 장애물은 Y→X 순서로 정규화한다.

Simulation asmdef는 No Engine References이며 테스트 어셈블리는 Editor 전용이다. 현재 불변 초기 상태만 제공하며 Tick이나 변경 명령은 없다.
