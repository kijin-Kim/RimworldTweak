## 검토 중 수정

조리 행을 작업표 열로 오인한 진단 검사의 범위를 실제 우선순위 표로 고쳤다. 그룹 명령 조기 반환이 버튼 배치를 건너뛴 겹침, 긴 그룹 소집 문구, 상세를 펼쳐도 설정이 화면 아래에 있던 스크롤, 중지와 작업 가능의 상충 문구를 보완했다.
맵 전체가 화면 안에 있어야 한다는 카메라 제한 때문에 가장자리 대상이 HUD 뒤에 남았다. 중심을 맵 좌표 범위 안에서 이동하게 해 가장자리도 중앙화한다. 따라서 가장자리에서는 맵 바깥 배경을 볼 수 있다.
기존 위치 보기 검사는 카메라 이동 전에 가리던 상세도 닫도록 보완한 뒤 통과했다.

## 판정 범위와 현재 차이

계획한 현재 기능 UI 개선과 에이전트가 실행할 수 있는 검증을 완료했다. 원본 게임의 물리 조작 재현과 사용자의 새 빌드 직접 플레이 체감은 미검증이다. 자동 검사·진단 렌더를 사람의 실제 조작 수락으로 기록하지 않는다. 이 추가 수락을 구현 완료의 선행 조건으로 요구하지 않는다.
그룹 이동은 각 정착민에게 같은 목적 칸의 기존 이동 명령을 보낸다. 대형 배치는 별도 모델이 필요하다. 현재 작업 우선순위0~3과1/3배속, 현재 생산 재료1종을 사용한다. 원본의 강제 작업/행동 큐, 건강·일정·연구 등 새 도메인은 사용자가 선택한 현재 기능 UI 범위와 구분한다.

## 실행과 추가 확인

실행 파일은 Builds/Windows/RimworldTweak.exe.
Tab/F1으로 패널 전환, 드래그와Shift로 복수 선택,R 소집과 우클릭 이동, 대상 우클릭 메뉴, 연속 건설·구역 지정, 작업표 우클릭, 조리 행별 상세와 초상 호버를 확인할 수 있다. 실제 체감 피드백은 후속 보완에 반영한다.
