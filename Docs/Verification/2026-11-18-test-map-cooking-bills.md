## 직접 확인

실행 파일은 이 작업 폴더의 Builds/Windows/RimworldTweak.exe.
실행 명령은 아래와 같다. 새 검사 저장은 별도 폴더를 사용한다.

~~~powershell
& 'C:Userskijin.codexworktrees
imworld-feature-bRimworldTweakBuildsWindowsRimworldTweak.exe' --storage-root 'C:Userskijin.codexworktrees
imworld-feature-bRimworldTweakTestResultsManualBills'
~~~

1. 새 정착지를 시작한다. 휠로 확대/축소하고 WASD 또는 휠 버튼 드래그로 외곽을 본다. 기존보다 넓은 맵에 외곽 나무/식물이 있어야 한다.
2. 건축가의 채집 도구로 나무/식물을 포함해 역방향과 한 칸 드래그한다. 포함된 대상만 지정되고 우클릭은 도구를 취소해야 한다.
3. 채집한 목재로 조리대를 만들고 식용 식물을 채집해 식재료를 준비한다. 조리대 선택 후 상세를 연다.
4. 계획서를 추가하고 목록 항목을 선택한다. 수량/반복/중지/위아래/삭제를 조작한다. 선택한 항목만 바뀌고 화면이 계속 열려 있어야 한다. 아래 설정은 상세 창 안에서 스크롤한다.
5. 작업자, 식재료 허용, 탐색 거리, 바닥/저장 구역을 바꾼다. 금지/거리0이면 새 재료를 가져오지 않고, 지정 회수 소진 후 멈춰야 한다. 지정 저장 구역에 공간과 식사 허용이 있으면 조리사가 완성품을 그곳으로 운반해야 한다.
6. 계획서와 생산 진행이 있는 상태에서 저장하고 불러온다. 설정과 재료/진행이 이어지고 중복 생산이나 소실이 없어야 한다.
