공격 준비9/10에서 통로를 막으면 피해 없이 준비가 초기화됐고, 통로 해제 후 한 번 사격해 적 체력이 50에서 25로 줄었다. 재명령 뒤 공격 대기 10Tick 동안 추가 피해는 없었다. 치료39/40에서 소집하면 약 소비와 체력 회복이 0이었고 환자 점유가 풀렸다. 같은 지점의 실제 JSON 복원에서는 다음 Tick에 한 번만 회복했다. 수리39/40의 복원에서도 목재2개를 한 번 소비하고 내구도40을 회복했다.

Windows 시설 시나리오에서는 조리 진행10/40과 식재료2개를 가진 조리대를 실제로 고장 냈다. 적 철수 후 재접근하여 수리한 뒤 기존 공정을 한 번 완료했다. 침대 수리는 별도 EditMode에서 피격과 점유 해제부터 다시 사용 가능해지는 지점까지 확인했다. 고장 난 벽 위에 정착민이 있으면 목재 소비 없이 완료를 보류했고, 칸이 비자 목재2개를 한 번 소비하고 통행 차단을 복원했다. Player 종료 로그에는 이전부터 있던 ComputeBuffer/D3D12 4096B 경고가 남아 있다.

첫 렌더에서 시험 습격 버튼과 저장 버튼이 겹치는 문제를 찾아 별도 열로 옮겼고 최종 PNG에서 분리된 위치를 확인했다. 최신 빌드·실행은 같은 입력으로 수행했다. 현재 제품 입력 246개의 파일 집합과 SHA-256을 Player 실행 기준과 대조해 추가·변경·누락0건을 확인했다. 사람이 실제 마우스와 키보드로 조작한 확인은 대기다.

## 직접 확인

실행 파일은 `E:/Dev/RimworldTweak/Builds/Windows/RimworldTweak.exe`다. 아래는 사람의 마우스·키보드 조작과 상황 이해를 확인하는 순서다.

1. 오른쪽 아래 **전투 시험**을 누르고 맵의 조리대를 클릭한 뒤 **시험 습격**을 누른다. 정지 상태에서 적 2명의 진입 표시와 예고 100틱이 보여야 한다.
2. 정착민을 선택해 R로 소집하고 우클릭으로 이동을 지정한다. 재개해 적이 나타나면 정지하고 **공격 지정**을 누른 뒤 맵의 적을 클릭한다. 정지 중에는 표적만 설정되고 체력은 그대로여야 한다.
3. 재개해 사격과 근접 피해를 확인한다. 사거리 밖에서 공격을 지정하면 선택한 정착민의 정보에 사거리 밖이라고 표시돼야 한다. 교전이 끝나면 결과와 부상 인원 수가 보여야 한다.
4. 행동 가능한 정착민의 소집을 해제한다. 부상자가 있으면 치료자가 의약품을 가져와 치료하고, 치료 후 정착민의 체력이 최대40만큼 회복돼야 한다. 손상 시설을 선택하면 **수리 지정**으로 목재 반입과 진행을 확인할 수 있다.
5. 교전 또는 치료 도중 **저장 덮어쓰기 → 불러오기 → 현재 진행 교체**를 실행한다. 시간·체력·적 위치·진행이 저장 시점으로 돌아와야 한다. 초기화하면 적과 습격 기록이 사라져야 한다.

답변 예시는 “모두 정상” 또는 “공격 지정 버튼을 눌렀는데 적 클릭이 선택으로 처리됨”이다. 제품 저장은 `settlement-v2.json`을 사용한다. 이전 `settlement-v1.json`은 건드리지 않으며 자동 이전은 없다.
