## 직접 확인 순서 (아직 사람 검증 전)

1. 위 실행 파일을 실행하고 Space로 정지한 뒤 **건설 / 재배 → 침대 → 빈 칸**을 클릭한다. Tick은 그대로이고 설계도가 보이며 도구는 해제되어야 한다.
2. Space로 재개한다. 목재를 반입한 뒤 침대가 완공되어야 한다. 정착민이 졸리면 새 침대도 선택할 수 있다. 당장 졸리지 않으면 자동 수면을 기다리는 것이 정상이다.
3. 정지 후 **재배 구역 → 빈 칸 두 모서리**를 클릭한다. 밭/작물이 구분되고 도구는 해제된다. 재개하면 파종하고 성장한다. 성장만240게임초이며3배속에서 약80실제초다.
4. 작업 중인 정착민을 선택해 정지 상태에서 R을 누른다. 소집과 점유 해제가 즉시 표시되고, 현장 자재·진행은 보존되어야 한다. R 해제 후 재개하면 작업을 다시 고른다.
5. 밭을 선택해 **파종 끄기**를 누른다. 설정은 즉시 바뀌며 이미 자란 작물은 계속 성장/수확한다. 식재료 저장에는 목재와 다른 빈 저장 칸이 필요하다.
6. 완공 시설을 선택해 **철거 지정**한다. 정지 중에는 지정/사용자 해제만 반영되고, 재개하여 담당자가 철거를 완료하면 시설이 사라지고 목재가 반환되어야 한다.

답변 예: “모두 정상” 또는 “재배 구역을 한 번 만든 뒤에도 도구가 남음”. 실제 마우스/키보드 조작감은 자동 UI 이벤트 검사나 PNG 검사로 대체하지 않는다.

## 남은 범위

조리대는 건설/철거와 남쪽 서비스칸 확보까지만 동작한다. 조리 주문·생산·출력, 개인 작업 우선순위 UI, 파일 저장/불러오기는 아직 구현하지 않았다. 전투/Fog of War와 장기 자급·밸런스도 이번 범위가 아니다. 기존 Player 종료 시 ComputeBuffer GC/D3D124096B 경고는 별도 잔여 관찰 사항이다. 사람의 새 기능 직접 플레이 확인은 대기다.

제품/검사/문서는 커밋하지 않았고 원격 연결/push도 없다. 다음 단계 조리·작업계획은 사용자 착수 지시 후 진행한다. SA/SB worktree는 후속 작업을 위해 유지하며, 새로운 기준을 받을 때 S0의 입력 manifest와 먼저 대조한다.
