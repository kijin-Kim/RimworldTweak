# 전투 독립 규칙 교차 검토

2026-11-17. [범위/계약](../Plans/Combat-Rules-Foundation.md). 코드 작성 완료 후 A/B가 서로의 전용 소스와 검사를 읽었고 S0가 양쪽 및 규칙 연결 검사를 검토했다. 이 문서는 실행 통과 증거가 아니다.

| 관점 | 검토 및 반론 | 반영 |
|---|---|---|
| A → B 장비 | 입력·결과 분리, immutable 자료, min(피해,방어력)로 음수/overflow 방지. 기본 0피해는 유효. | 계약과 일치, 필수 수정 없음 |
| B → A 사선 | 축 사거리 검사 뒤 long 제곱/교차곱, 모서리 양옆 칸 포함, endpoint 제외, 엄폐 최댓값. 별도 slab oracle로 80방향을 대조한다. | 계약과 일치, 필수 수정 없음 |
| B → S0 연결 | ResolveAssumedHit는 테스트 안 호출 예이며 제품 공격 API가 아니다. 보유 Session 비교는 실제 맵 어댑터 증거가 아니다. | 최종 보고와 검증 표에서 규칙 연결과 게임 연결 구분 |
| S0 | 방어구는 명중 여부를 결정하지 않으며 엄폐를 피해 감소로 재사용하면 안 된다. | 정면/측면 cover 50/0, 피해20-방어6=14로 명시 검사 |
| A 한계 | 매우 긴 유효 사거리는 선 길이에 비례한 조회 비용. callback은 질의 동안 동일한 읽기 상태를 제공해야 한다. | 시험 최대 사거리12, 성능 최적화는 범위 밖. 호출자 계약에 명시 |

설계 합의는 제품 검증을 대체하지 않는다. 실제 실행 결과는 별도 검증 기록에 남긴다. 건강/작업 취소/실제 지도/저장 버전의 통합 검증은 후속이다.
