# 게임 기획

## 방향

전투 기획의 현재 진행 원칙은 [림월드식 기본 전투 우선·점진 확장](Plans/Combat-Baseline-Incremental.md)이다. 유지할 개별 지휘·사격·엄폐·무기 역할·부상/복귀를 먼저 확인하고 이후 필요한 기능을 하나씩 선택한다. 장기 목표는 보존하되 제압·보급·Fog of War·원정의 전체 도입과 순서는 아직 확정하지 않는다.

2026-11-17 전투 논의 확장: [준비형 전투·공격 원정·보급 초안](Plans/TacticalCombat-Offense-Logistics.md)에 전술 대응 관계와 역사적 참고, 림월드식 개별 지휘 유지/전술 규칙 보강/분대 지휘 대안, 공격 목표·철수·보급·Fog of War를 정리했다. 사용자 요청은 기획 보존과 확장 검토이며 전투 구현이나 세부 규칙 확정이 아니다. 현재 방어 기준은 유지하고 공격의 완전작전 기준은 제안으로 구분한다.

정착지를 운영하며 정보를 수집하고 방어를 준비한 뒤, 습격에 대응하는 생존 전략 게임이다. 핵심 감정은 “내가 준비한 대응이 맞아떨어졌다”이다.

림월드의 생활·작업·생산·건설 구조를 참고하되 전체 시스템 재현을 목표로 하지 않는다. 림월드의 무피해 승리가 불가능하거나 부상이 필수라는 주장은 하지 않는다. 본작은 준비와 결과의 인과관계를 더 명확히 보여주는 것을 차별점으로 삼는다.

## 핵심 순환

정착지 운영 → 정보 수집 → 방어 준비 → 전투 지휘 → 결과 확인 → 운영 개선.

- 식량과 자재 생산이 정찰 인력과 방어시설을 뒷받침한다.
- 관측 범위는 적 발견 시점과 대응 시간을 바꾼다.
- 준비된 배치, 사선, 예비대와 후퇴 경로가 피해를 줄인다.
- 결과 화면은 탐지·교전 시점, 피해, 자원 소비, 침투 경로를 보여준다.

## 확정된 조작과 완전작전 기준

- 평상시에는 자율 작업을 기본으로 하며 플레이어가 작업과 우선순위를 지정한다.
- 전투에서는 일시정지와 직접 명령을 사용한다.
- 완전작전은 습격 시작부터 종료까지 아군 신규 부상 0, 정착민 사망·납치 0, 해당 습격의 보호 목표 유지다.
- 탄약 소비와 방어시설 손상은 허용한다. 시설을 희생해 사람을 지켜도 성공이다.
- 완전작전에 실패해도 치료·복구 후 계속 플레이한다.
- 완전작전의 우선 보상은 인력 손실과 회복 시간을 피하는 운영상 이익이다. 별도 성장 보너스는 미정이다.

## Fog of War 설계안

| 상태 | 정보 |
|---|---|
| 미탐색 | 지형과 적을 알 수 없음 |
| 탐색했으나 현재 비관측 | 지형·건물은 마지막 관측 상태, 적의 현재 위치는 모름 |
| 현재 관측 | 시야 내 최신 지형·건물·적 정보 |

정착민과 고정 관측소가 시야를 제공하며 벽과 지형이 차단한다. 적의 마지막 발견 위치에는 경과 시간을 표시한다. 숨겨진 적의 선택, UI 갱신, 자동 추적을 통한 정보 누출도 막아야 한다. 적도 관측한 정보에 따라 행동하도록 설계한다.

정보를 숨기는 만큼 정찰 수단과 대응 시간을 제공한다. 소리·날씨·야간 장비·센서 교란은 초기 범위에 넣지 않는다. Fog of War의 표시 효과와 관측 판정은 구분한다.

## 전투 설계안

- 완전한 사선 차단물은 직접 사격을 막는다. 엄폐는 위험을 낮추지만 무적은 아니다.
- 강한 공격에는 준비 동작을 두어 이동·제압·후퇴할 시간을 준다.
- 제압, 사격 보류, 표적 지정, 예비대와 대체 방어선을 검토한다.
- 적은 목표 실패나 손실에 따라 철수할 수 있다.
- 초기 검증에서는 확률의 영향을 줄여 준비의 효과를 먼저 확인한다. 이후 노출된 교전 안에서 제한적인 확률 요소를 조정한다.

## 초기 습격 유형

| 유형 | 획득 정보 | 대응 |
|---|---|---|
| 정면 돌격 | 방향과 대략적 인원 | 엄폐, 집중 사격, 접근 지연 |
| 우회 침투 | 측면의 소규모 적 | 외곽 관측, 예비대, 측면 방어 |
| 장거리 압박 | 무장과 사격 위치 | 사선 차단, 안전한 이동, 측면 접근 |

초기 시험에서는 습격 시작 전에 적 구성과 목표를 확정한다. 플레이어 배치를 몰래 읽고 유형을 즉시 바꾸거나, 비관측 영역이라는 이유만으로 적을 갑자기 생성해 준비를 무효화하지 않는다. 잘 준비한 습격이 쉽게 끝나는 것도 허용한다.

## 개발 범위 순서

1. 생활과 생산이 유지되는 정착지.
2. 한 종류의 습격, 치료, 복구와 작업 복귀.
3. 정찰과 관측에 따른 대응 시간 차이.
4. 여러 습격에 대응하는 준비형 전투.
5. 정착부터 습격까지 연결되는 짧은 데모.

실제 구현 상태는 [Status](Status.md)를 따른다. 2026-11-17 사용자는 자급 정착지 플레이테스트를 현재 범위에서 제외하고 저장·불러오기와 UI·경험 정리, 아트 추가의 상세 계획을 요청했다. 아트 방향은 정착민·시설이 잘 구분되는 간결한 탑다운 2D로 확정했으며 [상세 계획](Plans/SaveLoad-UX-Art.md)의 규격과 도구는 추천안이다. 일정, 최종 게임명, 장기 목표 정착민 규모는 미정이다.
