# 채집·운반·저장 데모 확인

실행 파일: `E:\Dev\RimworldTweak\Builds\Windows\RimworldTweak.exe`

작업3 구현의 실제 사람 조작 확인용이다. 자동 검사와 구분한다. 최신 빌드·실행 결과는 [작업3 검증](Verification/2026-11-15-work.md)을 따른다.

## 현재 사용할 수 있는 기능

기존 3명 정착민·식사·침대에 나무 2개와 식물 2개가 추가된다. 자동으로 채집하도록 지정된 상태로 시작하지 않는다. 오른쪽은 작업 도구/물자 정보, 하단은 정착민 상태다. 탭 전환 없이 확인한다. [UI 안내](ReadableUiDemo.md)를 따른다.

`채집 지정`를 누르고 나무/식물 타일을 클릭하면 지정한다. `저장 구역`을 누르고 사각형의 두 모서리를 클릭하면 저장 구역을 만든다. R은 선택 정착민 소집/해제이며, 소집한 뒤 우클릭으로 이동한다. 도구 사용 중 우클릭과 Esc는 도구 취소다. 정지 상태에서는 지정·구역·필터 명령을 접수하고 다음 Tick에 적용한다. 저장 구역 도구는 Esc 또는 우클릭으로 해제한다.

## 직접 확인할 순서

1. **지정과 입고:** 일시정지 후 `채집 지정`로 나무·식물을 지정한다. `저장 구역`으로 왼쪽 가장자리의 빈 타일 4칸을 선택한다. 재개 후 정착민이 먹고 쉬면서 지정 대상을 채집하고 물자를 저장 칸으로 옮기는지 확인한다. 목재10/식재료4씩 생산되며 물자 총량에는 운반 중인 것도 포함된다.
2. **운반 중 R:** 상단 정착민 버튼으로 운반 중인 Pawn을 선택한다. 일시정지 후 R을 누르면 Tick 증가 없이 행동·점유가 풀리고 물자가 현재 타일에 남아야 한다. 우클릭 이동은 즉시 명령되고 자동 생활이 덮어쓰지 않는다. R 해제 후에는 생활부터 다시 판단한다.
3. **생활 우선:** 포만도30 또는 휴식20에 도달하는 정착민을 관찰한다. 먹을 음식이 있으면 식사를, 피곤하면 수면을 우선한다. 다른 Pawn의 소집으로 침대가 비면 바닥 수면자가 재선택한다. 식량이 전혀 없을 때 식물 채집이 반복 취소되어 멈추지 않아야 한다.
4. **필터·삭제와 복구:** Esc로 도구를 끝내고 저장 칸을 클릭한다. 물자와 구역이 겹치면 `다음 오브젝트`로 저장 구역을 선택한다. `[x] 목재`를 끄면 목재는 삭제되지 않고 미보관으로 바뀐다. 다시 허용하면 재입고한다. `저장 구역 삭제`도 물자는 남긴다. 공간이 없을 때 정착민 상태에 보류 이유가 표시된다.
5. **시간과 초기화:** 정지 중 두 모서리 명령의 대기 표시, 한 Tick, 1/3배속을 확인한다. 초기화는 지정·구역·운반물·선택·미리보기를 지우고 초기 물자와 대상을 복원한다. 정지 여부와 배속은 유지한다.

결과는 “모두 정상” 또는 “운반 중 R을 누르면 …”처럼 재현 순서와 함께 알려주면 된다. 이 확인은 커밋 승인이 아니다.

## 아직 없는 기능

나무·식물은 한 번 채집하면 소진된다. 재성장·농사·조리·건설·개인별 노동 우선순위·파일 저장·전투는 미구현이다. 장시간 방치하면 유한한 식량이 소진되는 것은 현재 범위의 한계이며 자급 완료를 의미하지 않는다. 나무와 식물은 이번 단계에서 이동을 막지 않는다.
