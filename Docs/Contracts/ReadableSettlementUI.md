# 식별 가능한 맵과 하단 선택 패널 계약

2026-11-15 추천안 구현 승인. 채집·운반·저장은 사용자가 정상 작동을 확인했다. 이번 범위는 UI/표시이며 Simulation 규칙·시간·점유·명령 의미·패키지 버전은 유지한다. 커밋과 Computer Use는 하지 않는다.

## 확정 동작

| 단위 | 구현 계약 | 검증 기준 |
|---|---|---|
| UI-1 정착민 | ID별 고정 색상과 사람 형태. `1 · 정착민` 이름을 항상 표시. 선택 테두리/소집 배지는 별도 | 이동·소집·Reset에도 ID/색상/이름 일치. 같은 타일의 여러 Pawn 이름도 분리 |
| UI-2 오브젝트 | 나무=줄기/수관, 식물=잎, 식사=접시, 식재료=바구니, 목재=통나무, 침대=베개/매트리스. 이름과 물자 수량 표시 | 색을 제외해도 다른 모양, 올바른 이름·수량. 같은 칸 물자는 묶음 표시와 전체 목록 선택 |
| UI-3 저장 구역 | 반투명 바닥색과 구역 외곽선. 내부 타일 경계 강조 없음. 선택된 칸만 용량 표시 | 물자/정착민보다 아래 렌더. 다른 구역과 구분. 삭제·필터 변경·Reset 반영 |
| UI-4 선택 패널 | 화면 하단에 선택 대상 이름·현재 행동·운반물·목적지·실제 점유 대상·욕구 막대·수치·R 버튼 | 월드 읽기 상태와 매 프레임 일치. 도착 목적지와 점유 대상 구분. 식사/수면/노동/소집/대기 한눈에 확인 |
| UI-5 선택 연결 | 점유 대상 선택/위치 강조 버튼, 객체 목록 순환, 선택 Pawn 경로와 점유 대상 테두리 | 다른 대상 오선택 없음. 대상 삭제/행동 취소 후 잔류 강조 없음 |
| UI-6 통합 | 채집→운반→R→생활 복귀를 하단 패널로 추적 | 기존106개 회귀와 신규 표시 검사, Windows 렌더. 실제 사람 확인 별도 |

## 레이아웃과 입력

1280×800 기준 상단은 정착민 목록과 시간 조작, 중앙은 맵과 작업 도구/물자 요약, 하단은 선택 정보다. 기존 Life/Work 전환을 필요로 하지 않게 만든다. 맵 위치·크기가 바뀌어도 화면 좌표→타일 변환은 BoardRect 실제 크기를 기준으로 한다. 우클릭·R·Esc·정지/배속/한 Tick의 명령 의미는 유지한다.

색상은 식별의 보조다. Pawn ID·이름·사람 모양을 함께 표시하며 선택 색상이 고유 색상을 덮어쓰지 않는다. 점유 배지는 실제 OwnerId/OwnerActionId에 해당하는 Pawn 색/번호를 사용한다. 접근/사용은 하단 설명으로 구분한다. UI는 점유를 만들거나 추정하지 않는다.

형상은 외부 이미지 없이 Unity UI의 벡터 메시로 생성한다. 글꼴은 Windows의 한국어 지원 시스템 글꼴을 사용하며 빌드에서 한글 출력 여부를 검사한다. 글꼴 파일을 임의로 복사/배포하지 않는다. 새 장식 에셋·게임 규칙·카메라 줌/팬은 범위에 포함하지 않는다. '위치 보기'는 현재 맵 내 대상 타일 강조다.

## 소유권

이번 요청은 병렬 에이전트 배정 지시가 없으므로 root 단독으로 순차 수정한다.

| 소유자 | 파일 범위 |
|---|---|
| root | `Assets/Game/Presentation/SettlementView.cs`, `.Work.cs`, 신규 `.Inspection.cs`, `MapSymbolGraphic.cs`, 필요 시 `WorldMarker.cs`, `BoardPointerHandler.cs` |
| root | 관련 PlayMode 표시/입력 검사와 신규 UI 검사, DemoBootstrap의 UI smoke·렌더 시나리오, 검사 manifest |
| root | Docs/계약·상태·검증·사용자 확인 안내, README, 신규 원본의 .meta |

Simulation·Runtime의 게임 규칙은 수정 대상이 아니다. 구현 중 읽기 접점이 부족하면 먼저 계약에 근거를 기록한다. 기존 미커밋 채집 작업은 보존한다. Unity 실행 전 입력을 동결하고 root만 검사→빌드→Player를 직렬 실행한다.

## 검증 방법

자동으로 실행 가능한 항목: ID→색상/표시 이름, 심볼 종류 구분, 표시 수량/점유/목적지 정확성, 대상 선택, 실제 UI 입력 경로, Reset 잔류, 여러 해상도의 Rect 경계, 회귀106개. 실제 Player PNG를 보고 이름 겹침·마커 순서·한글·잘림을 점검한다. 사람의 가독성·마우스 사용감 확인은 사용자에게 별도로 요청한다. 통과 수만으로 사람 확인을 완료 처리하지 않는다.
