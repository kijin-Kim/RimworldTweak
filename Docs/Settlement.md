# 1단계: 생활과 생산이 유지되는 정착지

## 목표와 제외 범위

정착민 3명이 스스로 먹고 쉬며 플레이어가 지정한 건설과 생산을 이어간다. 초기 식사가 소진된 뒤에도 자체 생산으로 생활을 유지하는 것은 후속 자급·밸런스 목표다. 현재는 생활·생산 기능의 연결과 정확성을 먼저 검증하며 이 목표 달성을 전투 착수 조건으로 삼지 않는다.

포함: 허기·피로, 채집·운반·건설·농사·조리, 작업 우선순위, 생산 목표량, 저장과 불러오기.

제외: 전투·습격·Fog of War, 기분·관계·정신 이상, 상세 신체·기아 사망, 연구·거래·외교·월드맵, 전력·온도·지붕·방 품질, 부패·계절·병충해, 세부 일정표.

## 초기 시나리오와 조정값

아래 수치는 확정 밸런스가 아닌 첫 시험값이다. 변경 시 이유와 검증 결과를 함께 기록한다.

| 항목 | 초기안 |
|---|---|
| 통합 시험 맵 | 고정 맵 약 64×64타일, 전부 공개 |
| 작업 0 시험 맵 | 약 8×8타일, 이동·생활 기능 없음 |
| 인원 | 기본 능력이 같은 정착민 3명 |
| 초기 물자 | 식사 18개, 목재 40개 |
| 자원 | 목재, 식재료, 식사 |
| 시간 조작 | 일시정지, 1배속, 3배속 |
| 벌목 | 나무 1개 → 목재 10개 |
| 비상 채집 | 식용 식물 1개 → 식재료 4개 |
| 농사 | 타일당 작물 1개, 파종 후 게임 시간 2일, 수확 6개 |
| 조리 | 식재료 2개 → 식사 1개 |
| 비상 생식 | 식재료 4개 → 식사 1개에 해당하는 포만도 |
| 식사 빈도 목표 | 1인당 게임 내 하루 약 2회 |
| 조리 목표량 | 식사 12개 유지 |

3명이 하루 식사 6개를 소비한다면 식재료 12개가 필요하다. 이론적으로 경작지 4타일은 이틀 소비량만 충족하므로 노동과 지연의 여유가 없다. 초기에는 8~12타일을 시험한다. 정확한 욕구 감소·회복량과 작업 소요 시간, 현실 시간과 게임 내 하루의 대응은 구현 전 해당 작업에서 정하고 검증한다.

## 생활 규칙

- 포만도·휴식도는 0~100이며 높을수록 충족된 상태다.
- 포만도 30 이하에서 안전하게 작업을 중단하고 식사한다.
- 휴식도 20 이하에서 수면하고 90 이상에서 종료한다. 둘 다 부족하면 식사를 우선한다.
- 침대가 없으면 바닥에서 느리게 회복한다. 식사가 없으면 비상 생식한다.
- 포만도 0의 지속은 경고와 작업 능력 저하를 발생시킨다. 검증상 식량 유지 실패로 기록한다. 저하 수치는 미정이다.
- 건설 진행은 현장에, 조리 재료와 진행은 작업대에 남는다. 운반 중 물자는 안전하게 내려놓는다.
- 생활 종료 후 현재 우선순위로 작업을 재선택한다. 이전 작업으로 강제 복귀하지 않는다.

## 작업과 자원

자원은 맵에 실제로 존재하며 사용 장소로 운반해야 한다. 작업 종류는 벌목·채집, 농사, 건설, 조리, 운반이다. 각 정착민에게 끄기 또는 1~3 우선순위를 설정하며 1이 가장 높다.

선택 순서: 긴급 생활 → 수행 가능한 개인 우선순위 → 가까운 작업 → 먼저 요청된 작업. 거리 기준과 세부 동률 처리는 작업 구현 시 고정한다.

- 진행 중 작업을 더 가까운 작업이 생겼다는 이유만으로 취소하지 않는다.
- 같은 작업·자원을 중복 예약하거나 소비하지 않는다.
- 접근 불가 작업은 보류하고 통행 변화 후 재평가한다.
- 건설·조리 담당자가 재료를 직접 가져올 수 있다. 운반 담당자는 저장을 통해 이동 부담을 줄인다.
- 일할 것이 없으면 대기 상태를 표시한다.

## 건설과 저장

설계도 배치 → 자재 운반 → 건설 → 완공 순서다.

| 시설 | 목재 비용 | 기능 |
|---|---:|---|
| 벽 | 2 | 이동 차단과 공간 구획 |
| 문 | 4 | 정착민 통행 |
| 침대 | 10 | 빠른 휴식 |
| 조리대 | 15 | 식사 생산 |
| 저장 구역 | 0 | 허용 자원 보관 |
| 경작 구역 | 0 | 파종과 수확 |

취소 시 운반 자재를 현장에 반환한다. 철거는 초기에는 자재 전량 반환이다. 저장 필터를 제공하되 저장 우선순위는 제외한다. 저장 공간이 차면 자원을 보존하고 운반을 보류한다. 완성품은 작업대 출력 위치에 남으며 출력 공간도 차면 생산을 보류한다.

## 반복 생산과 화면

- 사용 가능한 식사와 진행 중 생산량을 고려해 목표량까지 조리한다. 목표 도달 시 중단, 소비 후 재개한다.
- 경작지는 수확 후 재파종한다. 파종 중지 상태에서는 기존 작물만 수확한다.
- 중단 이유를 식재료 부족, 담당자 없음, 접근 불가, 출력 공간 부족, 목표 도달로 구분한다.
- 자원 수량, 예상 식사 일수, 정착민 욕구·행동, 작업 우선순위, 시설 비용, 생산 목표를 표시한다.
- 식재료와 완성 식사는 별도로 표시한다. 경고를 선택하면 관련 대상으로 이동한다.

## 기능 완료와 후속 밸런스 기준

현재 기능 완료 기준은 실제 건설→재배→수확→조리→섭취 연결, 중단·원인 해소 후 재개, 물자 보존, 저장 복원 후 진행 유지다. 충분한 시험 자원으로 기능을 재현할 수 있으며 생산량·소비량의 장기 균형을 통과 조건으로 요구하지 않는다.

아래는 후속 작업8의 자급·밸런스 완료 기준이며 현재 기능 구현 및 전투 착수의 선행 조건이 아니다.

초기 식사를 소진한 뒤 최소 두 번의 재배·수확 주기 동안 정착민 3명이 자체 식량으로 생활한다. 포만도 0, 자원 유실·복제, 영구 작업 정지가 없어야 한다. 초기 설정 후 개별 행동을 반복 지시하지 않는다. 저장 복원 후에도 유지하고, 통로 차단·공간 포화·재료 부족은 원인 해소 후 정상 복귀해야 한다.

검증 시나리오는 [Testing.md](Testing.md), 기능별 작업 순서는 [Roadmap.md](Roadmap.md)를 따른다.

## 생활 기능의 구현 전 세부 계획

작업2의 기존 생활 임계값을 유지한 식사·수면·예약·이동 연계와 시험 수치는 [상세 계획](Plans/Task2-Needs-Food-Sleep.md)에 정리했다. 새 시험 하루·감소량·회복량·행동 시간·수동 명령 정책은 구현 전 추천안이며 최종 밸런스나 이미 구현된 기능을 뜻하지 않는다.

생활 기능의 시험 수치·식사/수면 규칙·이동 연계는 [작업2 계획](Plans/Task2-Needs-Food-Sleep.md)으로 구체화했으며 [생활 계약](Contracts/Living.md)에 따라 구현했다. 자동 검증과 사람 확인 상태는 Status 기준이다.

다음 변경은 [R 소집·상호작용 단일 점유 계획](Plans/Interaction-Occupancy-Draft.md)이다. 명령 취소와 점유 해제, 바닥 수면자의 빈 침대 재선택을 포함하며 구현·자동검증했다.

현재R/점유규칙과최종87개검사·Windows결과는 [점유검증](Verification/2026-11-15-occupancy.md)을따른다. 이전검증수치는당시버전의기록이다.
